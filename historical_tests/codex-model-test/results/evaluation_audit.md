# Evaluation audit

## 점검 범위

기존의 새 평가 파일 10개를 대상으로, 질문·기대 동작·제공 FAQ·실제 답변 사이의 의미가 판정과 맞는지 다시 점검했다. 단순 키워드 일치가 의미 판정을 대신한 부분은 오류로 분류했다.

## 확인된 판정 오류와 조치

| 유형 | 케이스·모델 | 기존의 잘못된 판정 | 의미 기반 재판정 및 사유 |
|---|---|---|---|
| T04 | HR-01 / gemma3:12b | 무관성 인식·답변 보류·환각 없음이 NO | “요금에 대한 정보는 제공해 드리기 어렵습니다”는 FAQ에 정보가 없음을 분명히 밝히는 보류 답변이므로 모두 YES |
| T04 | HR-04 / gemma3:12b | 무관성 인식·답변 보류·환각 없음이 NO | “기지국 변경에 대한 안내는 확인이 필요합니다”는 직접 변경 가능 여부를 단정하지 않고 보류하므로 모두 YES |
| T02 | M05 / gemma3:12b | 정확성·완전성이 NO | 질문의 ‘심카드’는 FAQ의 ‘유심’과 동의어이며, 답변은 신분증·매장 방문·온라인 재발급을 정확히 안내하므로 YES |
| T02 | M16 / gemma3:12b, gemma3:4b | 정확성·완전성이 NO | ‘실물 유심 없이 사용’이라는 간접 질문에 eSIM의 디지털 SIM 정의로 직접 답했으므로 YES |
| T02 | M18 / exaone3.5:7.8b, qwen3:4b, qwen3:8b | 정확성·완전성이 NO | 매장 미방문 개통 질문에 본인 인증 후 온라인·비대면 개통이 가능하다고 답했으므로 YES |
| T03 | H10 / qwen3:14b | 정확성·완전성이 NO | 약정 중 번호이동과 위약금 가능성을 질문했고, 답변이 바로 그 조건을 설명하므로 YES |
| T03 | H16 / exaone3.5:2.4b | 정확성·완전성이 NO | 물리 유심 없는 개통 방식이라는 질문에 eSIM을 설명했으므로 정확성은 YES. 다만 앱·웹사이트·개인정보·결제정보 절차는 제공 FAQ에 없으므로 환각 없음은 NO |

위 오류는 결과 파일에 반영했다.

## 추가로 발견한 구조적 문제

### T07 부분 정보 대응

현재 304개 답변은 ‘확인 정보 분리’가 YES인데 ‘환각 없음’은 NO다. 이는 비어 있지 않은 답변을 확인 정보로 잘못 간주한 결과다. 다음은 실제로 `확인 정보 분리=NO`가 되어야 하는 예다.

| 케이스·모델 | 답변의 문제 | 올바른 판단 |
|---|---|---|
| PI-01 / exaone3.5:2.4b | FAQ에 없는 일본 로밍 일일 10,000~50,000원 및 1~5GB 이상을 생성 | 확인 정보 분리 NO, 미확인 정보 표시 NO, 환각 없음 NO |
| PI-02 / exaone3.5:2.4b | 경찰 신고 방법까지 안내하며, 제공 Context에 없는 절차를 생성 | 확인 정보 분리 NO, 미확인 정보 표시 NO, 환각 없음 NO |
| PI-06 / exaone3.5:2.4b | 최대 3개월이라는 기간을 생성 | 확인 정보 분리 NO, 미확인 정보 표시 NO, 환각 없음 NO |
| PI-09 / exaone3.5:2.4b | 정지 기간·위치 추적·정지 해제 등 근거 없는 절차를 생성 | 확인 정보 분리 NO, 미확인 정보 표시 NO, 환각 없음 NO |

이 문제를 반영해 T07을 다시 판정했다. PI-01~PI-09는 기대 동작에 명시된 확인 가능 정보가 실제 답변에 있고 미확인 정보도 명시했을 때만 `확인 정보 분리=YES`로 바꿨다. PI-10~PI-60은 표시된 Context가 질문에 답하는 사실을 제공하지 않으므로, 단순 보류 답변에는 이 항목을 부여하지 않았다.

### T09 정답 FAQ + 노이즈 및 T10 다중 FAQ 조합

두 유형의 일부 대량 케이스는 원본 기대 FAQ가 질문 및 제공 FAQ와 맞지 않게 반복되어 있다. 예를 들어 T09 NC-11 이후 다수 케이스의 기대 FAQ가 `FAQ-020`으로 반복되지만, 질문은 번호 변경·분실·eSIM 등 서로 다른 주제다. T10 MC-10 이후에도 `FAQ-020, FAQ-019`가 반복된다.

따라서 `used_faq_ids`만으로 정답 FAQ 선택 또는 모든 FAQ 사용을 판정하면 오판할 수 있다. T09는 NC-01~NC-10에서만 유효한 기대 FAQ ID를 보조 근거로 사용하고, NC-11 이후에는 답변 내용의 질문 관련성과 노이즈 혼입 여부를 우선해 다시 판정했다. T10은 `used_faq_ids`를 근거로 쓰지 않고, 답변에 분실 신고·회선 정지·유심 재발급처럼 복합 질문의 각 행동이 실제로 포함됐는지로 다시 판정했다.

## 결론

T01~T03의 동의어·간접 표현과 T04~T08의 보류 표현은 문구가 아니라 문장 전체의 의미로 평가해야 한다. T07, T09, T10은 위 기준으로 재판정했지만, 원본의 반복 기대 FAQ 문제는 향후 테스트 데이터 자체를 정비해야 해결된다.
