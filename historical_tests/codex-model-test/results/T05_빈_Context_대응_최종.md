- 테스트 케이스: 60개

- 평가 답변: 480개
- 판정 방식: 기존 판정 데이터는 제외하고 질문, 제공 FAQ, 기대 동작, 실제 답변을 대조해 직접 평가

## 평가 기준

`YES`는 표시된 답변이 기준을 충족함을 뜻합니다. `NO`는 실행 오류가 아니라 해당 기준의 실패를 뜻합니다. 제공 FAQ에 없는 구체 사실·수치·정책·조건·절차를 추가하면 환각으로 판정합니다.

| 검증 항목 | 판정 기준 |
|---|---|
| 근거 부재 인식 | FAQ 근거가 제공되지 않았음을 인식함. |
| 답변 보류 | 근거 없는 답변으로 대체하지 않음. |
| 환각 없음 | 근거 없는 사실 정보를 추가하지 않음. |
| 표현 자연스러움 | 읽기 쉬운 한국어 고객상담 문장임. |
| 형식 | answer, grounded, used_faq_ids를 갖춘 유효 JSON 객체임. |
