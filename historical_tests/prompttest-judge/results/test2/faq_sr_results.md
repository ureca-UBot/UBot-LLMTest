## 채점 기준 (컬럼 설명)

정답 유사도/100=기존 코사인 유사도 ×100. 의미 유사도 열은 같은 값의 원래 단위다. 키워드 포함률은 기존 문자열 포함 비율이다. RAG 충실도=기존 NLI의 근거 지지 문장 수/판정 문장 수. 표현=기존 100점 규칙. 포맷=7개 형식 조건 충족 수. 응답 시간은 ms, TPS는 초당 생성 토큰 수다. 상태 일치는 기대 응답 상태와의 정확한 일치이며 별도의 의도 분류 시험이 아니다. [분모와 한계](methodology.md)를 함께 읽는다.

기존 저장 결과만 재집계했다. **정답 유사도/100**은 기존 BGE-M3 코사인 값 ×100이며 실제 정답률이 아니다. **RAG 충실도(근거 지지율)**는 기존 NLI에서 근거가 지지한다고 판정한 문장 수/판정 문장 수다. 숫자·명사·출처 오류는 접이식 자동 진단에 별도로 남겨 두었다. **포맷 충족/7**은 저장된 응답의 7개 형식 조건 충족 수다. 반복 표는 3개 회차 쌍의 일치 비율이다. 상태 일치는 일치/불일치, 재판단 필요 여부는 있음/없음으로 표시하며 재판단 완료를 뜻하지 않는다. 스킵·미채점·판정 없음은 0점으로 환산하지 않는다. 이 표의 수치는 추가 모델 호출 없이 계산했다. 중단한 별도 재채점 결과는 사용하지 않았다. **AI 내용 재판단 결과**는 기존 234건의 AI 검토 의견을 성공·실패로 정리한 판정이다. 모호한 의견 19건은 저장된 답변을 추가 확인했다. 내용 정확성을 판정하며 상태 코드·형식·근거 ID 배열·말투만의 문제는 별도 지표로 남긴다. **성공률=성공/(성공+실패)**, 실패율도 같은 분모다. 판정 보류·미재판단을 0점이나 실패로 넣지 않는다. 개별 성공·실패에 확신도 퍼센트를 붙이지 않는다. [판정 기준·모델별 성공률](ai_rejudgment_results.md)을 참고한다.
