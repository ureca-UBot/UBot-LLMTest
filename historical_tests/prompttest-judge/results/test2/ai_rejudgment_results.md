## 판정 범위와 기준

기존 26개 공통 표본 × 9모델의 AI 검토 의견을 답변 내용 성공·실패로 정리. 모호한 의견 19건은 저장된 답변을 추가 확인. 생성 모델·별도 평가 모델 호출 없음. 중단한 추가 재채점 캐시는 사용하지 않음.

질문에 필요한 핵심 사실·조건·예외·확인 불가 내용을 보존하고, 내용 반전·요구 정보 누락·근거 밖 정책/수치/절차 추가가 없으면 성공. 부가 설명의 사실 오류도 실패. 상태 enum·JSON 형식·근거 ID 배열·말투만의 문제는 이 내용 판정에 합산하지 않고 기존 별도 지표와 진단에서 확인. 근거가 충분하지 않은 경우 판정 보류.

성공률=성공/(성공+실패), 실패율=실패/(성공+실패). 판정 보류·미재판단은 분모에서 제외하고 별도 건수 표시. 검토 완료 비율=(성공+실패+판정 보류)/해당 범위 전체. 개별 판정에 0%·100%나 확신도를 부여하지 않음.

이 결과는 기존 의견을 이번에 성공·실패로 정리한 것으로, 원래 자동 채점 파일에 최종 AI 판정이 저장되어 있었다는 뜻이 아니다. 재판단 필요 표시만으로 성공·실패를 추정하지 않았다. 고유 300문항 중 의도적으로 고른 공통 26문항만 검토한 표본이며, 이 성공률을 전체 300문항 또는 380회 정답률로 확대할 수 없다. 모델 간 순위를 확정하는 통계 추정도 아니다.

총 검토 기록 234/3420 (6.8%), 성공 126건, 실패 107건, 판정 보류 1건, 미재판단 3186건. 판정완료 233건 기준 성공률 54.1%, 실패율 45.9%. 반복 2·3회차에는 회차1 판정을 복사하지 않았다.
