## 3. 해석

1. **누락은 되돌아왔다.** 50자 삭제 + 조건 보존 문장으로 v5_i2에서 떨어진 MC·MT·PI·NC·UI가 모두 v4_base 수준 이상으로 회복했다. 누락만으로 오답은 165 → 30으로 v4_base(44)보다 적다. SETUP 5절대로 두 변경 중 어느 쪽 효과인지는 가를 수 없다.
2. **CE는 v4_base보다 떨어졌다(68 → 57, p=0.035).** 누락이 아니라 내용 모순이 늘었다(CE 오답 중 모순 26 → 37). 경계값 문항에서 답은 맞게 시작하고, 뒤에 덧붙인 설명에서 조건을 틀리게 바꿔 말한다.
   - CE-0053·0055: "20GB 소진 후 1Mbps"를 "20GB를 초과하면"으로 바꿔 말함
   - CE-0041·0058: 계산해 놓고 "확정할 수 없다"고 덧붙임
   - CE-0076: 4회선 할인 합계를 8,800원으로 잘못 계산(정답 35,200원)
   
   "조건·단서와 계산 결과를 줄이지 않는다"가 조건 재진술·계산을 늘렸고, 거기서 틀린 것으로 보인다(추정).
3. **v5_i2의 개선 중 되묻기만 남았다.** 되묻기는 1 → 2로 유지됐다. 하지만 환각은 80 → 126, 본문 FAQ ID 노출은 16 → 184로 다시 늘었다. ID 노출은 v4_base(137)보다도 많다("FAQ-145에 따르면" 같은 출처 표기, MT 43 · UI 52 · CE 33 · NC 26). "사용자는 자료를 볼 수 없다" 문장만으로는 긴 답에서 ID 노출을 막지 못한다. 50자 제한이 그동안 길이로 막고 있었던 것이다.
4. **SR 꼬리 문장은 크게 돌아오지 않았다**(환각 13 → 15, v4_base 28). 감시 목적은 통과다.

## 4. 다음 안 후보

원인 분석([failure_analysis](summary/failure_analysis.md)) 뒤 정한 우선순위는 그 문서 4절을 따른다. 1순위는 답변 틀 2번(불가 문장)을 조건부로 바꾸고 과정 서술("따라서"·질문 되풀이·출처 전제)을 금지하는 것, 2순위는 ID 문장 교체다. 아래는 처음 정리한 후보다.

- **유지**: 50자 제한 삭제, 조건 보존 문장(누락 회복), 되묻기 금지.
- **ID 노출**: 출처 표기 금지를 구체적으로 쓴다(예: "본문에 FAQ 번호나 '~에 따르면'을 쓰지 않는다 — 번호는 evidence_ids에만"). t1b에서 따옴표 예시가 그 표현을 늘린 적이 있으므로 예시 없이 쓰는 안과 비교한다.
- **CE 모순**: 조건 보존 문장을 "FAQ 문구 그대로 옮긴다"는 쪽으로 바꾸거나, 이미 확정한 계산 뒤에 "확정할 수 없다"를 덧붙이지 말라는 문장을 검토한다.
- **환각 일반화**: v5_i2 수준으로 낮추려면 답변 틀(확정 답 + 답할 수 없는 부분 한 문장)을 더 지키게 할 방법이 필요하다. 길이 제한 없이 "FAQ에 없는 설명을 덧붙이지 않는다"의 효과를 따로 본다.
- 이번에 뺀 CF·AR·HR·AD(+안전성)는 다음 안을 정할 때 함께 다시 잰다.
