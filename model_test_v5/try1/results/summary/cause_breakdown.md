# 환각·오답 원인 비율 — Qwen3-4B-Instruct vs qwen3:4b OFF (튜닝 1~3차 포함)

작성일: 2026-10-08 · 스크립트: `scripts/docgen/cause_breakdown.js` · 판정: Judge `v4-judge-12`(`paths.jsonl` + `accuracy.jsonl`)

[prompt_tuning_transfer.md](prompt_tuning_transfer.md)는 원인을 **건수**로 비교했다. 오답·환각 총량이 모델마다 달라서, 건수가 줄었다고 그 원인이 덜 중요해졌다고 볼 수는 없다. 이 문서는 **실제로 생긴 환각과 오답 가운데 몇 %가 어떤 원인인지**를 본다.

**한 줄 요약:** Instruct는 과잉 보류가 사라진 대신 오답의 2/3가 환각에서 나온다. 그중 창작·오귀속·충돌 선택(처리 완료 포함)이 오답의 약 55%이고, 꼬리 문장은 8~9%다. 누락은 건수만 줄었고 비율은 OFF와 같은 23%다.

## 1. 정의

- **대상**: 같은 1,300건(14항목 × 100, 반복 항목 RT 제외). OFF = `qwen3:4b` 추론 OFF + `v4_base`(v4 try1을 100 서브셋으로 다시 집계한 `v4-try1-n100`), Q4·Q8 = Instruct + `v4_base`(`v5-try1-n100`).
- **환각 응답**: Judge `is_grounded = false`. 원인은 Judge가 적은 `hallucinated_claims`(주장 문장·이유·type)를 아래 순서로 처음 걸린 하나로 분류한다.
  1. 처리 완료·사칭 수용: type `FALSE_COMPLETION` 또는 "완료/처리/접수 + 되었/했"
  2. 자료에 없는 확인 경로·연락처: 고객센터·114·전화번호·상담원·홈페이지·대리점·"문의", "(앱|메뉴|매장) … 확인/조회/신청/변경해", "확인해 주시/하시기/하시면"
  3. 충돌 임의 선택·우선 규칙 창작: type `SILENT_CONFLICT_PICK`, 또는 CF 항목에서 "문서 A/B·우선순위·최근·최신·기준 시점·시행"
  4. 추가 정보 요청 꼬리: "알려주시면·제공해 주시면·정보가 필요·더 정확한 답변"
  5. 추측·상식 일반화: type `UNSUPPORTED_GENERALIZATION`, 또는 "~에 따라 다르/달라·다를 수 있·일반적으로·보통·대부분·통신사별·정책에 따라"
  6. 오귀속: type `MISATTRIBUTION`
  7. 값·조건·절차 창작: 나머지(`FABRICATION`)
- **환각 쪽 비율**: 포함률은 그 원인 주장이 하나라도 있는 환각 응답의 비율(겹침 허용)이다. 단독률은 주장이 모두 그 원인인 환각 응답의 비율로, 그 원인만 없애면 환각에서 빠지는 응답이다. 오답 전환율은 그 원인이 들어간 환각 응답 가운데 오답의 비율이다.
- **오답 원인(배타)**: 위에서부터 처음 걸린 하나로 정한다. 과잉 보류(기대 ANSWER·PARTIAL인데 본문 ABSTAIN·OUT_OF_SCOPE) → 환각 동반 → 필수 사실 누락 → 다른 FAQ 내용 사용·사실 오적용 → 충돌 미고지 → 보류해야 하는데 답함 → 기타. 환각 동반 오답은 응답의 주된 환각 원인으로 다시 나눈다. 이때 내용 창작(완료·충돌·오귀속·값 창작)이 꼬리 문장(경로·추측·정보 요청)보다 먼저 걸린다.
- **분류 검증**: 원인별 주장 문장을 표본으로 확인했다. 경로 정규식은 "앱 내에서 기록되어"·"조회할 수 없습니다" 같은 오탐을 빼도록 좁혔다. 정규식 분류라 몇 건씩은 경계가 흐리다.
