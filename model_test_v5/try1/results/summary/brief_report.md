# v5 try1 평가 요약

작성일: 2026-10-08 · 배치: `v5-try1-n100`

## 평가 범위와 완료 상태

Qwen3-4B-Instruct-2507(Q4_K_M · Q8_0)과 Gemma 3 4B IT QAT를 14개 항목 × 100건, 모델당 1,400건으로 평가했다. 생성은 v4와 같은 EC2 Tesla T4 · Ollama 0.34.2 · temperature 0 · 고정 컨텍스트 · `v4_base` 프롬프트이고, Q4_K_M은 v4 try1에서 생성한 n200 run의 100 서브셋을 그대로 가져왔다. 판정은 Codex CLI `gpt-6-sol` · `medium` · 루브릭 `v4-judge-12`다. 생성 실패·타임아웃은 0건이다.

정확도 4,200건·안전성 300건·페르소나 300건 중 **4,799/4,800건** 판정에 성공했다. 미채점 1건은 Gemma QAT의 `HR-0163`이다. 6번 모두 CORRECT 판정과 누락·모순 표시가 충돌해 검증에서 거부됐고, 모델 오답으로 세지 않았다.

v4 기준선(같은 1,400건으로 재집계): `gemma3:4b` Q4_K_M 정답률 64.5% · 환각률 24.3%, `qwen3:4b` OFF 62.2% · 22.8%. 자세한 비교는 [v4_comparison.md](v4_comparison.md).

## 해석

1. **8bit(Q8_0)는 4bit(Q4_K_M)보다 정확하지 않다.** 정답률 차이 1.3%p는 같은 문항 짝 검정에서 유의하지 않고(p=0.22), 환각률도 같다(p=0.85). 맞히고 틀리는 문항의 85.4%가 같다. 반면 Q8_0은 응답이 1.34배 느리고 생성 속도가 28% 낮다. 이 과제에서는 가중치 8bit가 정확도에 주는 이득이 없다.
2. **Qwen3-4B-Instruct가 v4의 두 4B 모델보다 크게 낫다.** v4 `qwen3:4b`(추론 전용 Thinking-2507을 추론 OFF로 사용)보다 정답률 +15.3%p, 정답+근거+상태 +39.2%p다. v4에서 가장 약했던 PI·CE·UI의 정답률이 24~55%p 올랐다(PI 18% → 73%, CE 26% → 67%, UI 35% → 59%). 다만 Instruct는 **JSON 스키마의 키 순서를 따르지 않고 답을 먼저 썼다**(2,800건 전부 `answer → evidence_ids → status`). 그래서 출력 순서 차이가 결과에 섞여 있다.
3. **Gemma QAT는 Q4_K_M보다 낫다고 보기 어렵다.** v4 `gemma3:4b`(Q4_K_M) 대비 정답률 +2.5%p(p=0.065, 유의하지 않음), 환각률 +7.4%p(p<0.001), 응답 0.3초 느림. 같은 4bit라도 QAT를 쓸 이유가 확인되지 않았다.
4. **약한 항목은 여전히 AR·CF·UI다.** Instruct Q4_K_M 기준 AR 52% · CF 47% · UI 59%. AR은 다섯 모델(v4 포함) 모두 38~52%이고, 공통 오답 후보 233건 중 AR이 가장 많아 문항·기대 답 검토가 필요하다.

판단과 다음 단계는 [quantization_decision.md](quantization_decision.md)에 정리했다. 최종 모델 선정은 아니다.

## 해석 범위와 원자료

대표 품질 지표는 반복 테스트(RT)를 제외한 채점 성공 행 기준이다(QAT 1,299건, Instruct 각 1,300건). 근거 관련 지표는 근거 판정 대상 행(851)이 분모다. 안전성은 AD, 페르소나는 지시가 있는 행만 평가했다. 지연·TPS는 T4 순차 단일 요청 기준이며 동시성 판단에 쓰지 않는다. Q8_0은 FP8(W8A8)의 정확도 대리이고 FP8 자체를 잰 것은 아니다.
