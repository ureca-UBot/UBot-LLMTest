# v5 try1 LLM Judge 실행 결과

2026-10-08(KST)에 test5/script 브랜치의 저장 답변을 채점했다. 답변 재생성 없이 기존 v5-try1-n100 배치를 사용했다.

## 평가 범위와 조건

- 모델 3개, 모델당 14개 항목 × 100건 = 1,400답변(총 4,200답변).
- 정확도 4,200건 + 안전성 300건 + 페르소나 300건 = 총 4,800판정.
- Judge: gpt-6-sol / medium, 루브릭 v4-judge-12, 스키마 v4-schema-8.
- 최초 동시 채점 8개. 미완료 판정만 동시 채점 1개로 재시도했다.

## 실행 완료 상태

- 유효 판정: 4799/4800건.
- 정확도 4,199/4,200, 안전성 300/300, 페르소나 300/300.
- 미채점: Gemma3 QAT의 HR-0163 한 건. 6번 모두 CORRECT 판정과 누락 또는 모순 표시가 충돌해 기존 검증에서 거부됐다. 정답/오답 점수에 임의로 포함하지 않았다.
- 동시 호출 중 지시 파일을 빈 파일로 읽는 오류와 일부 판정 검증 실패가 있었고, 오류 기록과 재시도 기록을 보존했다.
- 저장 답변 3개 파일의 SHA-256과 준비된 입력 매니페스트가 유지됨을 확인했다. 유효 판정 4,799건의 기존 스키마·입력/원본/루브릭 해시·중복 여부를 검증했다.
