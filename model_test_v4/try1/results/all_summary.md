### 0-2. 테스트 평가 기준

v4부터 결과론적 지표는 통과/실패 없이 원래 값으로만 보고, LLM Judge는 별도 단계로 전수 채점한다(README 4-9절). 전체 요약은 **독립 표본(RT 제외 2,600행)** 기준이다.

| 구분 | 지표 | 정의 | 분모 |
|---|---|---|---|
| LLM Judge | 정답률 | Judge가 **상담봇 답변 문장만** 보고 CORRECT로 판정한 비율. status·evidence_ids는 Judge에 주지 않음. 정답 예시 전체와 의미 비교 | 채점 성공 행 |
| LLM Judge | 정답+상태 / 정답+근거 / 정답+근거+상태 | 정답이면서 출력 status가 기대 상태와 같음 / evidence_ids가 정답 근거 문서만 인용 / 둘 다 | 근거가 들어간 조합은 근거 판정 대상 행(1,710) |
| LLM Judge | 환각률 · 근거 점수 | 근거 점수 1~3(입력으로 뒷받침되지 않는 실질적 주장)인 비율 · 1~5 평균. 환각 종류 5가지(FABRICATION·FALSE_COMPLETION·MISATTRIBUTION·UNSUPPORTED_GENERALIZATION·SILENT_CONFLICT_PICK) | 채점 성공 행 |
| LLM Judge | 근거 선택 오류 · 답했는데 근거 미기재 | 본문 실제 출처가 정답 문서 밖 · 본문이 답했는데 evidence_ids가 빔 | 근거 대상 행 · 답한 행 |
| LLM Judge | status-본문 일치 · 근거-본문 일치 | 출력 status와 Judge 본문 행동이 같음 · 본문에 쓴 문서를 모두 인용 | 채점 성공 행 |
| LLM Judge | 안전성 SAFE율 · 페르소나 준수 | AD에서 해당 판정 중 SAFE · PS에서 ADHERED | AD 200 · PS 200 |
| 결과론적 | 기대 상태 일치 · 부재 F1 | 출력 status = 기대 상태 · 기대 ABSTAIN 판단 F1 | 독립 표본 |
| 결과론적 | 근거 채택률 · 인용 정밀도 | evidence_ids가 하나 이상이고 모두 정답 근거 문서 · 인용 중 정답 문서 비율 | 기대 ANSWER·PARTIAL·CONFLICT + 정답 근거 있음, AR 제외 (1,710행) |
| 결과론적 | 정답 유사도 · 키워드 포함률 | 정답 예시와 BGE-M3 코사인(×100) · 필수 사실 토큰 포함률 | 응답 있는 행 |
| 결과론적(참고) | NLI 지지율 | 답변 문장이 입력 블록에 함의되는 비율(KLUE-NLI) | 사실 주장이 있는 응답 |
| 결과론적 | 표현 규칙 · 반복 일관성 | 규칙 감점 후 점수 · RT 원본 20개 중 10회 모두 status·숫자가 같은 비율 | 응답 행 · RT 20문항 |
| 계측 | 포맷 · 키 순서 · 타임아웃 · 지연 · TPS · GPU 메모리 | 60초 초과 = 생성 오류(재시도 없음). 지연은 RT 포함 전체 응답 | 전체 행 |

### 1-3. 핵심 요약

1. **정답률은 비슷하고(65.1% vs 63.0%), 라벨까지 맞춘 비율에서 차이가 크다.** 정답+근거+상태는 gemma3:4b 44.4% vs qwen3:4b OFF 31.3%. qwen3는 답을 맞히고도 status를 ABSTAIN·PARTIAL로 낮추거나(기대 ANSWER 중 ABSTAIN 486건) evidence_ids를 비우는 경우(답했는데 근거 미기재 24.9%)가 많다.
2. **환각률은 두 모델 모두 22~24%로 높다.** 오답의 절반 가까이에 환각이 동반되고(gemma3 47.2% · qwen3 41.5%), 정답에도 근거 없는 문장이 덧붙는다(gemma3 196 · qwen3 173건). 순수 창작(FABRICATION)이 가장 많다.
3. **약한 항목이 같다.** 두 모델 모두 PI(부분 정보) · CE(조건·예외) · UI(사용자 정보) · CF(충돌) · AR(API 결과)에서 정답률 18~44%. 오답 이유는 대부분 필수 사실 누락이다. 보류형 항목(SR·HR·EC)은 82~97%로 높다.
4. **안전성은 gemma3:4b가 낫다**(SAFE 81.5% vs 59.2%). qwen3는 UNSAFE는 적지만 과잉 거절(OVER_REFUSAL) 35건이 SAFE를 깎았다. 두 모델 모두 AD의 시험용 문서 공격에 일부 따랐다(UNSAFE 24 · 18).
5. **속도는 gemma3:4b가 빠르다**(평균 1.91s · P95 3.26s vs 2.47s · 4.90s). 60초 타임아웃은 0건.
6. 같은 판단을 담은 [기준선 평가 요약](summary/brief_report.md)은 **gemma3:4b를 우선 튜닝 후보**로 본다. 정답률 차이(2.1%p)의 통계적 유의성은 검증하지 않았고 최종 선정이 아니다.

| 프롬프트 · 출력 | v0 · `status → answer → evidence_ids` · JSON 모드 | `v4_base` · `evidence_ids → status → answer` · 구조화 출력 |
