# v4 try1 기준선 평가 요약

작성일: 2026-10-06 · 배치: `v4-try1-n200`

## 평가 범위와 완료 상태

Gemma3 4B와 Qwen3 4B를 각각 14개 항목 × 200건, 총 2,800건으로 평가했다. 생성 조건은 temperature 0·추론 OFF·고정 컨텍스트이며, 판정 모델은 Codex CLI의 `gpt-6-sol`, 추론 강도는 `medium`이다. 답변 생성은 두 모델 모두 실패 없이 완료했다.

정확도 5,600건·안전성 400건·페르소나 400건 중 **6,398/6,400건(99.97%)** 판정에 성공했다. 재처리 후 Qwen의 실패 건은 해소됐으나, Gemma의 `AR-0145`, `AR-0147`은 정답 판정과 누락·모순 배열이 충돌해 검증에 실패했다. 두 건은 미채점으로 남겨 두었으며 모델 오답으로 간주하지 않았다.

## 해석과 후속 과제

**Gemma3 4B를 우선 튜닝 후보로 판단한다.** 이번 평가에서 답변 정답률은 2.1%p 높았고, 근거·상태를 함께 맞춘 비율과 안전성 SAFE율, 응답 속도에서도 우세했다. 다만 정답률 차이의 통계적 유의성을 검증한 것은 아니며 최종 모델 선정 결과는 아니다.

Qwen3 4B는 환각률이 2.1%p 낮고 페르소나 준수율도 조금 높았다. 그러나 답변하면서 근거를 기재하지 않은 비율이 24.9%로 높고, status와 본문이 일치한 비율도 67.9%로 Gemma의 77.1%보다 낮아 출력 정합성 개선이 필요하다.

두 모델 모두 사용자 정보 결합, 조건·예외, 부분 정보, FAQ 충돌, API 결과 답변에서 정답률이 낮았다. 다음 실험은 해당 항목의 근거 오류·사실 누락·오적용을 검토하고, 프롬프트 튜닝 전후의 정확도·환각·응답 시간을 같은 조건에서 비교한다.

## 해석 범위와 원자료

대표 품질 지표는 반복 테스트(RT)를 제외한 채점 성공 행 기준이다(Gemma 2,598건, Qwen 2,600건). 근거 관련 지표는 근거 판정 대상 행을 분모로 사용하며, 정답 판정과 환각 판정은 독립적이다. 안전성은 적대적 입력·범위 밖(AD), 페르소나는 지시가 있는 행만 평가했다. 고정 컨텍스트 실험이므로 검색·임베딩 성능을 포함하지 않으며, v3와는 정확도 정의가 달라 직접 비교하지 않는다.
