### RT-0004-R01 · Easy · 1회차 · Judge CORRECT

#### 제공 내역

**사용자 질문**

> 현재 2026-10-01이고 아직 요금제를 변경한 기록이 없습니다. 오늘 한 번 변경할 수 있나요?

**대화 이력**

(없음)

**제공 Context**

```
[FAQ-375] 추가 충전한 데이터와 기본 데이터 중 무엇이 먼저 쓰이나요?
기본 제공 데이터를 모두 사용한 뒤 충전한 데이터가 사용됩니다. 충전 데이터는 충전한 달 말일까지 유효합니다.

[FAQ-444] 넘버플러스는 월 얼마인가요?
넘버플러스는 월 3,300원입니다. 앱에서 신청하면 바로 이용할 수 있습니다.

[FAQ-130] 요금제는 한 달에 몇 번까지 바꿀 수 있나요?
요금제 변경은 한 달에 1회 가능합니다. 이번 달에 이미 변경했다면 다음 달에 다시 변경할 수 있습니다.
```

**정답 예시**

> 요금제 변경은 월 1회입니다. 10월 변경 기록이 없으므로 이번 달 1회 변경할 수 있습니다.

**기대 상태**: `ANSWER`

- **근거**: (빈 배열)
- **답변**:
