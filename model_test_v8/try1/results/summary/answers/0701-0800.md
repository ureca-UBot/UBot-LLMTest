## CORE-0701 · 데이터/속도 · USER_DATA

**질문:** 제가 데이터 안심 서비스에 가입돼 있나요?

**검색 FAQ:** 701 (1.0000), 950 (0.8935), 166 (0.8846)

**실행 상태:** ANSWERED / **모델 status:** PARTIAL

**가드 처리 전 LLM 답변:**

데이터 안심 서비스의 가입 여부를 확인하기 위해 회원의 부가서비스 정보를 조회해야 합니다. 제공된 FAQ에서는 가입 여부를 확인할 수 있는 절차를 설명하고 있지만, 실제 가입 여부는 조회 결과에 따라 달라지므로, 현재 가입 여부를 확인할 수 없습니다.

가입 여부를 확인하려면 부가서비스 정보를 조회해야 하며, 해당 조회 결과가 없기 때문에 확정할 수 없습니다.

**실제 제공 FAQ:**

- FAQ 701: 제가 데이터 안심 서비스에 가입돼 있나요?
  회원의 부가서비스 정보를 조회해 데이터 안심 가입 여부를 안내해 드립니다. 데이터 안심은 무료입니다.

- FAQ 950: 데이터 안심 서비스는 언제 신청한 거예요?
  회원의 부가서비스 이력을 조회해 데이터 안심 신청일을 안내해 드립니다.

- FAQ 166: 데이터 안심 서비스는 어떤 서비스인가요?
  데이터 안심은 기본 데이터를 모두 사용했을 때 추가 과금 없이 데이터를 차단해 주는 무료 부가서비스입니다.
