## CORE-0551

**질문:** 응암역 쪽에서 가족 대신 업무 볼 수 있는 매장을 찾아요.

**저장된 LLM 답변 — 가드 적용 전:**

> 응암역 주변에서 가족 대신 업무를 보는 매장을 찾아드리는 것이 가능합니다. 위임장과 명의자 인감증명서가 필요합니다.

**원판정:** INCORRECT / 근거 있음 / 점수 5/5

필요 서류와 대리인 업무 매장 안내 가능성은 FAQ에 근거가 있습니다. 다만 실제 매장 조회 결과가 없는데도 구체적인 매장을 안내할 수 없다는 점을 밝히지 않아 핵심 요청을 충족하지 못했습니다.

**재검토 의견:** INCORRECT / UNGROUNDED · `ADD_UNSUPPORTED_PROMISE`

위임장·인감증명서 안내는 근거에 있지만 응암역 매장을 직접 찾아드릴 수 있다고 한 약속은 실제 조회 도구가 없는 실행 조건에서 뒷받침되지 않는다. 매장 결과도 없다.

**실제 제공 FAQ:**

- **FAQ 551 — 응암역 쪽에서 가족 대신 업무 볼 수 있는 매장을 찾아요.**  
  응암역 주변에서 대리인 업무를 취급하는 매장을 찾아 드립니다. 위임장과 명의자 인감증명서가 필요합니다.

- **FAQ 403 — 어머니 대신 업무 보러 가려는데 어머니 댁 근처 매장을 찾아 주세요.**  
  어머니 댁 주소 주변에서 대리인 업무를 취급하는 매장을 찾아 드립니다. 명의자 신분증, 대리인 신분증, 위임장, 명의자 인감증명서가 필요합니다.

- **FAQ 660 — 사상역 근처에서 법인 업무 보는 매장을 찾아요.**  
  사상역 주변에서 법인 업무를 취급하는 매장을 찾아 드립니다.

**원판정의 누락 사항:** ["실제 매장 조회 결과가 없어 응암역 주변의 구체적인 매장을 안내할 수 없다는 점"]

## CORE-0554

**질문:** 독립문역 근처에서 요금제 상담받을 매장을 찾아 주세요.

**저장된 LLM 답변 — 가드 적용 전:**

> 독립문역 주변에서 요금제 상담이 가능한 매장을 찾아 드립니다. 현재 위치 기반으로 근처 매장을 추천해 드리는 서비스입니다.

**원판정:** INCORRECT / 근거 이탈 / 점수 3/5

답변은 매장 검색에 관한 일반 설명만 제시하고 구체적인 매장이나 조회 자료의 부재를 알리지 않아 핵심 요청을 충족하지 못했습니다. FAQ 문구와 별개로 현재 직접 찾아 주겠다는 약속은 실행 근거가 없습니다.

**재검토 의견:** INCORRECT / UNGROUNDED · `KEEP`

답변과 제공 FAQ를 대조했다. 실제 매장 목록·위치 정보 없이 직접 지역 취급점을 찾아드리거나 추천하겠다는 약속이 응답 핵심이며, 이 실행에는 이를 수행할 도구가 없어 요청을 해결하지 못한다.

**실제 제공 FAQ:**

- **FAQ 554 — 독립문역 근처에서 요금제 상담받을 매장을 찾아 주세요.**  
  독립문역 주변에서 요금제 상담이 가능한 매장을 찾아 드립니다.

- **FAQ 435 — 요금제 상담받으러 갈 가까운 매장 있나요?**  
  요금제 상담이 가능한 매장을 현재 위치 주변에서 찾아 드립니다. 요금제 변경은 앱과 고객센터에서도 할 수 있습니다.

- **FAQ 422 — 태블릿 요금제 가입하러 갈 매장을 찾고 있어요.**  
  현재 위치 주변에서 데이터 전용 회선 가입을 취급하는 매장을 찾아 드립니다.

**원판정의 누락 사항:** ["실제 매장 조회 결과가 없어 독립문역 근처의 구체적인 매장을 확인할 수 없다는 안내가 빠졌습니다."]

**원판정의 근거 이탈 주장:**

- `FABRICATION` 독립문역 주변에서 요금제 상담이 가능한 매장을 찾아 드립니다. — FAQ의 서비스 설명을 현재 상담봇이 직접 매장을 찾아 줄 수 있다는 약속으로 제시했지만, 이번 실행에는 매장 조회 수단이나 결과가 없습니다.
