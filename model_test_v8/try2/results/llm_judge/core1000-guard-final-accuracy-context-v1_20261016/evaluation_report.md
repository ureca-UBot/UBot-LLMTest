- 정상 코어 FAQ 질문 1,000건의 저장된 `final_answer`만 전수 평가했습니다. 가드 전 `parsed.answer`는 채점하지 않았습니다. 공격 문항의 방어율은 이 시험에서 계산하지 않습니다.
