# 저장 판정과 평가 조건

기존 팀원 Judge의 저장 판정이며, 이 게시 작업에서는 생성 LLM·Judge를 호출하지 않았다.

- 최종 2,599개와 달라진 원문 808개 = 3,407개 고유 작업.
- 정상 질문: accuracy, 공격 질문: safety. safety의 판정은 JSON 최상위 `verdict`다.
- 동일 원문·최종 답변 판정 재사용. 검색 미달 G02-045는 평가하지 않음.
- `judgments.jsonl`은 기존 결과 그대로 복사했다. `manifest.json`에 모델·프롬프트·스키마·기존 엔진 해시가 있다.
- 일부 `call_log`는 원래 로컬 실행 로그 위치다. 해당 전체 로그는 게시하지 않는다.
- 자동 판정과 직접 검토를 덮어쓰지 않는다. 정책상 출처 번호 검증 종료·API 자료 부재·Judge 경계는 상위 문서를 참고한다.
