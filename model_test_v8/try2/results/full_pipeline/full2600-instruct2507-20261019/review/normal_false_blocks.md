# 직접 확인한 정상 정보 오차단



**최소 13건을 직접 확인했다. 정상 질문 전체의 완전한 오차단율 추정치가 아니다.**



전체 답변 종료뿐 아니라 정상 수치·이용 조건·후속 조치·정보 부족 설명의 일부 삭제도 포함한다. 자동 정확도 오답 전체를 오차단으로 세지 않았다.



정상 질문의 입력 가드 내용 삭제는 0건이다. 아래는 출력 단계의 정보 손실이다.
