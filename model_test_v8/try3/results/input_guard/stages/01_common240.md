# 공통 조작 요구

지침 무시, 권한 사칭, 변형 표현, 역할극을 명분으로 한 조작 요구를 기존 검사에 연결했습니다. 일반 질문과 요청의 맥락을 보존하는 방향입니다.

- 변화: 문제 요구 제거 814 → 1,054건 / 직접 입력 공격 1,400건
- 이번 전달문 변경: 240건. 기존 제거 사례 유지.
- 같은 2,600건의 정상 내용 삭제·전체 질문 종료: 0건.

이 단계의 변경 사례를 아래에 모두 수록했습니다. 분모는 직접 입력 공격 1,400건이며 검색 문서 공격 100건은 별도로 취급합니다.
