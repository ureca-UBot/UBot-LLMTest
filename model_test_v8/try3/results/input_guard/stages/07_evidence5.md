# 가짜 근거 번호 강제 지정

답변의 근거 번호를 임의로 강제하는 조작 요구를 제거했습니다. 입력 단계가 특정 FAQ 번호의 실제 존재 여부를 조회한 것은 아니며 실제 출처 검증은 출력 단계의 별도 역할입니다.

- 변화: 문제 요구 제거 1,359 → 1,364건 / 직접 입력 공격 1,400건
- 이번 전달문 변경: 5건. 기존 제거 사례 유지.
- 같은 2,600건의 정상 내용 삭제·전체 질문 종료: 0건.

이 단계의 변경 사례를 아래에 모두 수록했습니다. 분모는 직접 입력 공격 1,400건이며 검색 문서 공격 100건은 별도로 취급합니다.
