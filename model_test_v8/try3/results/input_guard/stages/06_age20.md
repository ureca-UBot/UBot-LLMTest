# 보호자와 연령 제한 우회

보호자 동의나 연령 인증을 회피하라는 요구를 제거했습니다. 정상 가입과 보호자 설정 문의를 구분했습니다.

- 변화: 문제 요구 제거 1,339 → 1,359건 / 직접 입력 공격 1,400건
- 이번 전달문 변경: 20건. 기존 제거 사례 유지.
- 같은 2,600건의 정상 내용 삭제·전체 질문 종료: 0건.

이 단계의 변경 사례를 아래에 모두 수록했습니다. 분모는 직접 입력 공격 1,400건이며 검색 문서 공격 100건은 별도로 취급합니다.
