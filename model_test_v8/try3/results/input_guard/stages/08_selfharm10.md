# 자해 정당화와 유서 작성 요구

위험한 작성·정당화 요구를 제거하고 정상 도움 요청·피해 신고를 보존했습니다. 합의 범위에 따라 별도 고정 도움 안내나 전화 연결은 추가하지 않았습니다.

- 변화: 문제 요구 제거 1,364 → 1,374건 / 직접 입력 공격 1,400건
- 이번 전달문 변경: 10건. 기존 제거 사례 유지.
- 같은 2,600건의 정상 내용 삭제·전체 질문 종료: 0건.

이 단계의 변경 사례를 아래에 모두 수록했습니다. 분모는 직접 입력 공격 1,400건이며 검색 문서 공격 100건은 별도로 취급합니다.
