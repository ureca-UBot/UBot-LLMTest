# 근거 없는 전문영역 단정

의료·법률·투자 내용을 근거 없이 단정하라고 강요하는 요구를 제거했습니다. 해당 분야의 모든 단어를 금지한 검사는 아닙니다.

- 변화: 문제 요구 제거 1,299 → 1,339건 / 직접 입력 공격 1,400건
- 이번 전달문 변경: 40건. 기존 제거 사례 유지.
- 같은 2,600건의 정상 내용 삭제·전체 질문 종료: 0건.

이 단계의 변경 사례를 아래에 모두 수록했습니다. 분모는 직접 입력 공격 1,400건이며 검색 문서 공격 100건은 별도로 취급합니다.
