# 보완 전에 사용한 잔존 요구 분석

이 폴더의 586건과 346건은 보완 과정의 과거 분석 대상 수입니다. 현재 남은 건수는 최종 결과의 구독·가사 요구 10건이며, 아래 과거 수치와 혼동하지 않습니다.

- [보완 전 잔존 586건 분류](remaining586_before_changes.json): 초기 검사에서 남은 요구의 처리 범위를 정한 자료입니다.
- [공통 조작 240건 보완 후 잔존 346건 분류](remaining346_after_common240.json): 추가 입력 검사와 출력·근거 검사 역할을 나눌 때 사용했습니다.

이 분석 자체에서는 임베딩·LLM·Judge·DB나 가드 코드를 다시 실행하거나 수정하지 않았습니다. 후속 보완은 상위 폴더의 9단계 결과와 별도로 읽어야 합니다.
