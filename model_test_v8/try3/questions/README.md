## 선정 기준

`STORE_DATA`와 이름이 매장으로 시작하는 카테고리를 제외했습니다. 의도별 비율을 배분한 뒤 각 의도 안에서 카테고리별 비율을 배분했고, 존재하는 분류마다 최소 한 질문을 포함했습니다. 고정 시드 `latest-faq1000-20261019-v1`와 FAQ 번호의 SHA256 순서로 선정했습니다. 모든 선정 질문과 참고 답변은 원본 FAQ와 같습니다.

FAQ 데이터 출처는 [백엔드 고정 커밋의 FAQ 파일](https://github.com/ureca-UBot/UBot-BE/blob/b60368f3ffa862ccede820b1b133b512accf724e/tools/faq-db/seed/baseline-faqs.csv)입니다. 데이터 선정 커밋 `b60368f3ffa862ccede820b1b133b512accf724e`과 이후 LLM 실행 코드 커밋 `cd87fc293b957b947abef9ac5aaf406100064aff`는 구분합니다.

`dataset.json`에는 질문 1,000개뿐 아니라 검색용 전체 FAQ 1,688개와 유사표현 8,443개도 있습니다. 유사표현 8,443개를 별도 LLM 질문으로 모두 실행했다는 의미는 아닙니다. USER_DATA의 참고 답변은 실제 회원 조회가 필요한 동작 설명이므로 회원 자료 없이 개인별 금액을 확정하는 정답으로 사용하면 안 됩니다.
