### 0-2. 테스트 평가 기준

| 구분 | 평가 기준 | 정의 | 분모 |
|---|---|---|---|
| **LLM Judge** | 내용 정확도 | Judge가 CORRECT로 판정한 비율 (필수 사실·조건·기대 상태 충족) | 채점된 고유 문항 |
| **LLM Judge** | 근거율 (= 1 − 환각률) | 근거 점수 1~3점(고객이 오인할 수준의 근거 밖 내용)이 없는 답변 비율 | 채점된 고유 문항 |
| **LLM Judge** | 근거 점수 / 표현 점수 | 근거 충실도·한국어 표현 품질 1~5점 평균 | 채점된 고유 문항 |
| **LLM Judge** | 안전성 | 적대적 입력(AD) 지정 15문항의 SAFE / UNSAFE 판정 | AD 지정 15문항 |
| 결과론적(결정론) | 기대 상태 일치 | 응답 JSON의 status가 기대 응답 상태(ANSWER/PARTIAL/CLARIFY/ABSTAIN/CONFLICT/OUT_OF_SCOPE)와 같은 비율 | 고유 300 |
| 결과론적(결정론) | FAQ 부재 판단 F1 | 기대 ABSTAIN 88문항에 대한 ABSTAIN 예측의 Precision/Recall/F1 | 고유 300 |
| 결과론적(결정론) | 포맷 성공률 | 지정 JSON 스키마 준수 비율 | 고유 300 |
| 결과론적(결정론) | 정답 유사도 / 키워드 포함률 | BGE-M3 코사인 유사도(×100)와 필수 키워드 포함률 — 의미 정답률이 아님 | 고유 300 |
| 결과론적(결정론) | RAG 근거 지지율 (참고) | KLUE-NLI로 답변 문장이 제공 FAQ에 함의되는 비율의 평균. premise에 사용자 정보·대화 이력·API 결과가 빠지는 한계가 있어 **참고용** | 상태 기반 제외 후 측정분 |
| 결과론적(결정론) | 표현 규칙 점수 | 실격 3종 + 감점 5종 규칙 점수(/100) | 고유 300 |

| 계측 | 응답 시간 | 평균 / P95 (순차 단일 요청) | 실행 전체 |
| 계측 | VRAM | 모델 적재 시 GPU 메모리 | 모델별 |

### 1-3. 핵심 요약

- **1차 MVP 모델로 `qwen3:14b` 추론 OFF(temperature 0)를 선정했다.** 정확도 70.7% · 근거율 76.3% · 기대 상태 79.3% · 부재 F1 0.725 · P95 8.11s. 11개 설정을 "최하위 탈락" 방식(지표 순서 720가지·86,400가지 전수)으로 좁힌 결과이며, 최종 확정이 아닌 1차 MVP 선정이다 → [model_selection](summary/model_selection.md)
- **LLM Judge 정확도 1위는 `qwen3:14b` ON(75.6%)**, **근거율 1위는 `qwen3:4b` ON(86.3%, 환각률 13.7%)**이다. 다만 `qwen3:4b` ON은 P95 47.6s로 300문항 전부 5초를 넘겨 상담봇 기본 설정으로는 쓰기 어렵다.
- **`gemma3:12b`는 균형형 대안**이다(정확도 64.0% · 근거율 78.7% · 반복 일관성 95.0% · P95 7.28s). 다만 조건·예외·경계값(29.2%)·사용자 정보+FAQ(37.5%)에서 약하다.
- **추론 OFF는 지연을 크게 줄이지만 정확도 손실이 모델마다 다르다**: `qwen3:14b` −5.0%p, `qwen3:1.7b`·`qwen3:8b` 약 −16%p, `qwen3:4b` −28.7%p → [think_ablation](summary/think_ablation_results.md)
- **소형·비추론 모델의 하한**: `exaone3.5:7.8b`는 기대 ABSTAIN 88문항 중 0문항을 맞혀 부재 F1 0.000, `gemma3:4b`는 정확도 31.3% · 근거율 49.7%로 본측정 최하위권이다.
- 포맷 성공률(98.7~100%)과 LLM Judge 표현 점수(4.23~4.79)는 모델 간 폭이 좁아 변별력이 낮다.
