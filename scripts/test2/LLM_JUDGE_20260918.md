# 2026-09-18 저장 답변 AI 채점

대상은 `rerun-20260918-1328`의 5개 모델이다. 9월 17일 실행 결과는 대상에 포함하지 않는다.
고유 답변 1,500건에 정확도·환각·한국어 표현 품질을 함께 채점하고, 그중 적대적 입력 75건에 안전성 판정을 추가한다.
채점자는 `gpt-6-astra`, reasoning effort는 `medium`으로 고정한다. 기존 ChatGPT 로그인으로 실제 채점 호출과 결과 저장을 확인했다.

## 현재 상태

- 최종 집계 시 원본 답변 5개 파일의 해시, 결과 ID 중복, 채점 프롬프트 및 출력 형식 검증을 통과했다.
- 준비된 채점 입력과 5개 원본 답변의 해시 대조 완료.
- 채점 실행기, 형식 검증, 실패 기록, 성공 문항 재개 처리 구현.

- 사용자가 OpenAI Codex로 채점 데이터를 전송하는 것을 명시적으로 승인했다.
- 제한된 실행 환경에서는 인증 정보를 읽지 못했으나, 승인된 실행 환경에서 기존 ChatGPT 로그인이 확인됐다.
- 수정된 기준으로 실제 문항의 채점·저장·중단 후 재개가 성공했다.

- 기존 모델 생성, Ollama 호출, 원래 파이프라인 실행은 하지 않았다.

## 실행 환경

사용자가 질문·FAQ·대화 이력·사용자/API 정보·저장된 답변의 OpenAI Codex 전송과 새 기준에 따른 실행을 승인했다.
기존 ChatGPT 로그인으로 실행하며 인증 자료를 결과 파일이나 Git에 저장하지 않는다.

## 실행 및 재개

연결과 JSON 형식 확인에 사용한 명령은 다음과 같다. 최초 확인은 이미 완료했다.

```powershell
node scripts/test2/score_accuracy_hallucination_llm.js --limit 1
```

그다음 같은 작업 폴더에서 다음 명령으로 남은 채점을 실행한다. 이미 성공한 문항은 건너뛴다.

```powershell
node scripts/test2/run_saved_llm_judge.js --concurrency 8
```

이 명령은 `run_pipeline.js`, `run_generation.js`, `run_all_models.js`를 호출하지 않는다.
진입 프로세스는 한 개만 실행한다. 내부의 독립 문항 채점 요청만 최대 8개 동시에 처리하며, 각 요청은 이전 문항이나 다른 모델 답변을 문맥에 포함하지 않는다.
같은 출력에 두 진입 프로세스를 동시에 실행하지 않는다. 단계별 잠금 파일이 중복 실행을 방지한다.

## 출력

- `results/scored/test2/<오늘 run_id>/accuracy_hallucination_llm.jsonl`
- `results/scored/test2/<오늘 run_id>/safety_llm.jsonl`
- 위 두 항목의 `_summary.json`
- `results/llm_judge/test2/rerun-20260918-1328/`의 진행 상태와 호출 로그

오류·미채점은 0점이나 오답으로 집계하지 않는다. 실패 시도는 error로 남기고, 재개 시 성공 기록만 건너뛴다.
기존 원본 답변, 자동 채점 파일, 기존 보고서는 변경하지 않는다.
평가 완료 후 `node scripts/test2/build_llm_judge_report.js`로 5개 모델 비교 보고서를 생성한다.
보고서 위치는 `results/test2/V2/llm_judge/README.md`이며 모델별 문항 상세와 `judgments_V2.csv`를 함께 저장한다.
이어서 `node scripts/test2/build_results_V2.js`로 기존 자동 평가와 AI 점수·검수 메모를 합친 V2 비교표 및 CSV를 생성한다. 두 보고서 명령은 모델을 호출하지 않는다.

AI 결과 JSONL과 요약은 지시서의 `results/scored/test2/<run_id>/` 경로를 유지하고, 사람이 읽는 새 CSV와 보고서는 `_V2` 파일명 또는 `V2` 폴더로 구분한다. 기존 `run_pipeline.js`에는 자동 연결하지 않았으며, 이번 배치 전용 저장 답변 실행기를 제공한다. CLI 원시 호출 로그는 로컬 진단용으로 남겨두고 게시물에서 제외한다.

로컬 실행기 검증은 `node scripts/test2/verify_llm_judge.js`이며, 모델이나 네트워크를 호출하지 않는다.
