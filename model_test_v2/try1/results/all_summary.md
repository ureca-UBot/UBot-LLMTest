### 0-2. 테스트 평가 기준

| 구분 | 평가 기준 | 정의 | 분모 |
|---|---|---|---|
| **LLM Judge** | 내용 정확도 | Judge가 CORRECT로 판정한 비율 (필수 사실·조건·기대 상태 충족) | 채점된 고유 문항 |
| **LLM Judge** | 근거율 (= 1 − 환각률) | 근거 점수 1~3점(고객이 오인할 수준의 근거 밖 내용)이 없는 답변 비율 | 채점된 고유 문항 |
| **LLM Judge** | 근거 점수 / 표현 점수 | 근거 충실도·한국어 표현 품질 1~5점 평균 | 채점된 고유 문항 |
| **LLM Judge** | 안전성 | 적대적 입력(AD) 지정 15문항의 SAFE / UNSAFE 판정 | AD 지정 15문항 |

| 결과론적(결정론) | 포맷 성공률 | 지정 JSON 스키마 준수 비율 | 고유 300 |
| 결과론적(결정론) | 정답 유사도 / 키워드 포함률 | BGE-M3 코사인 유사도(×100)와 필수 키워드 포함률 — 의미 정답률이 아님 | 고유 300 |
| 결과론적(결정론) | RAG 근거 지지율 (참고) | KLUE-NLI로 답변 문장이 제공 FAQ에 함의되는 비율의 평균. premise에 사용자 정보·대화 이력·API 결과가 빠지는 한계가 있어 **참고용** | 상태 기반 제외 후 측정분 |

| 결과론적(결정론) | 반복 일관성 | 반복 40문항의 3회차가 status·숫자 모두 일치한 비율 | 반복 40문항 |
| 계측 | 응답 시간 | 평균 / P95 (순차 단일 요청) | 실행 전체 |
| 계측 | VRAM | 모델 적재 시 GPU 메모리 | 모델별 |

### 2-2. 해석

- **양 끝 순위는 유지됐다.** v1 RAG 안정성 상위 `qwen3:8b`(74.6%)·`qwen3:4b`(69.8%)는 v2 AI 재판단에서도 상위(84.6%·96.2%)이고, `gemma3:270m`·`gemma3:1b`·`qwen3:0.6b`는 두 버전 모두 하위권이다. 반면 v1 3위였던 `gemma3:4b`(68.3%)는 v2에서 중위권(AI 재판단 57.7%·기대 상태 46.3%)으로 내려갔다.
- **v1 FAQ 라운드의 변별력 부족이 드러났다.** v1 FAQ 정답률은 상위 5개 모델이 88.9~100%로 몰렸지만, 13개 항목의 v2에서는 기대 상태 일치가 14.0~83.0%로 크게 벌어졌다. 단순 재진술보다 "상태 판단(보류·부분·충돌)"이 모델을 가르는 축이다.
- **`qwen3:0.6b` 반전은 v2에서도 이어졌다**: v1 FAQ 정답률 77.8%로 높았지만 RAG 안정성 17.7%, v2 AI 재판단 30.8%·기대 상태 35.7%.
- v1은 전수 Judge, v2 try1은 결정론+표본이라 **Judge 신뢰도 면에서는 오히려 후퇴**했고, 이 공백을 try2의 LLM Judge 전수 채점으로 메웠다.
