## 3. 해석

**겨냥한 꼬리 문장·환각은 크게 줄었다**
- 환각 157 → 107. SR 47 → 21 · HR 39 → 25는 v4_t1(20 · 24) 수준으로 돌아왔다. UNSUPPORTED_GENERALIZATION 62 → 21.
- 환각 주장 중 "정책·통신사별로 다르다" 44 → 18, "확인 경로" 60 → 32, "일반적으로" 17 → 3(정규식 분류).
- 소속 정체성 + 확인 경로 문장 삭제 + 추측 예시 삭제의 효과다(세 가지의 기여도는 가를 수 없다).

**누락 감소는 유지됐고 MC는 더 좋아졌다**
- 누락만으로 오답 41 → 40, 누락 사실 120 → 106. MC 정답 79 → 88(p=0.035), MC 누락만으로 오답 14 → 8. 완결성 대상을 "질문의 답을 담은 FAQ"로 좁혀도 누락 감소 효과는 사라지지 않았다.

**남은 문제**
1. **SR 86 — v4_t1(96)까지는 못 돌아왔다**(v4_t1 대비 정답→오답 11 · 오답→정답 1, p=0.006). 남은 오답은 두 갈래다.
   - 확정할 수 없는 값을 단정: SR-0097 "일시정지 기간은 최대 30일", SR-0098 "일반적으로 30일", SR-0051·0057 "다음 달 청구 시점에 최종 확정", SR-0187 "명의 변경 횟수 제한이 없습니다".
   - 근거 없는 확인 경로: SR-0016 "구체적인 비용은 앱에서만 정확히 조회할 수 있습니다", SR-0192 "정확한 해지 반환금은 앱에서 조회할 수 있습니다".
   - SR status는 PARTIAL 28 → 23으로 아직 많다(v4_t1 3). "비슷한 문서의 내용 일부 + 확인 불가"로 답하는 틀이 남았다.
2. **NC 85 → 79**(정답→오답 9 · 오답→정답 3, p=0.146 — 유의하지 않지만 하락 방향), 환각 14 → 19. 오답 사유가 갈린다.
   - 헷갈리는 FAQ의 조건을 대상 질문에 적용(MISATTRIBUTION): NC-0052 분실 신고에 로밍 고객센터 번호 적용, NC-0181 취소된 위치 찾기 조건 적용.
   - **맞는 FAQ를 관련 없다고 판단**: NC-0050 "요금 연체 안내는 FAQ-042의 연체료·서비스 제한과 관련이 없습니다"(FAQ-042가 정답 근거), NC-0078 정답 FAQ에 조건이 있는데 "확인할 수 없다".
   - 해석(추정): 새 문장 "질문과 주제가 비슷해도 질문의 답을 담지 않은 FAQ의 내용은 옮기지 않습니다"가 모델에게 **어느 FAQ가 답인지 판단하게** 만들었다. 헷갈리는 FAQ가 일부러 섞인 NC에서는 이 판단이 틀리는 경우가 생기고, 그 판단을 본문에 문서 ID로 적는다(NC ID 노출 15 → 27).
3. **근거를 evidence_ids 대신 본문에 적는다**(결정론): 근거 미기재 70 → 103, ID 노출 123 → 170, NC 상태 일치 86 → 74(ANSWER → PARTIAL). 정답률에 직접 영향은 크지 않지만(PI·MC는 정답 유지·상승) 라벨·근거 필드의 신뢰도가 떨어졌다. 같은 2번 문장의 영향으로 보인다.
4. PI 환각 38(v4_t1 25)·HR 정답 82(v4_t1 87)는 아직 v4_t1보다 나쁘다. PI 환각 주장은 대부분 "기타(값·절차·조건 창작)" 33건이다.

## 4. 다음에 할 일

1. 근거 필드: 본문에 FAQ ID를 쓰지 말고 evidence_ids에 적으라는 문장을 완결성 문장 바로 뒤로 옮기거나, 출력 후처리로 본문 ID를 지우고 evidence_ids에 옮긴다(v1 문서 4-5절).
2. NC 하락: "답을 담지 않은 FAQ의 내용은 옮기지 않습니다"를 "질문에 답하지 않는 FAQ에 대해서는 설명하지 않습니다"처럼 **판단 결과를 말하지 않게** 바꾸는 안을 검토한다. 또는 이 문장만 뺀 안으로 NC·SR·HR만 다시 생성해 기여도를 가른다.
3. SR 값 단정: ABSTAIN 정의(status_rules)에 "자료에 없는 값은 일반적인 값으로도 제시하지 않는다"를 추가하는 안.
4. 문서: [summary/v3_change_effects.md](summary/v3_change_effects.md)에 변경별 판정을 정리했다.
