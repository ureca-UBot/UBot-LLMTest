## 3. 해석 (Judge 전, 결정론 지표 기준)

**겨냥한 꼬리 문장은 줄었다**
- 추측 표현 68 → 30, 통신사 언급 90 → 27, 자료에 없는 확인 경로 128 → 41. SR은 셋 다 v4_t1보다도 낮다(6 · 8 · 8). 소속 정체성 + 확인 경로 문장 삭제 + 추측 예시 삭제가 함께 효과를 냈다(세 가지의 기여도는 가를 수 없다).
- 남은 것: PI-0044 "일반적으로 15분 간격으로 반영", PI-0111 "일반적으로 당일 개통"(FAQ 원문 표현일 수 있어 Judge 확인 필요), PI-0039·SR-0001 "고객센터에 문의해 주세요"(자료에 없는 경로).

**새로 나빠진 것 — 근거를 evidence_ids 대신 본문에 적는다**
- NC·MC에서 ANSWER → PARTIAL로 바뀌고(NC PARTIAL 14 → 26, MC 2 → 9) evidence_ids를 비운 응답이 늘었다(근거 미기재 NC 7 → 22, MC 1 → 8, PI 34 → 49). 그런데 본문은 대부분 다 답했고, **본문에 문서 ID를 적어 출처를 밝힌다**.
  - NC-0071(evidence 빈 배열, PARTIAL): "매장 영업시간은 … 확인할 수 있습니다. **(FAQ-077)** … 필요한 신분증을 챙겨 주세요. **(FAQ-678)**"
  - NC-0087: "가족 결합 할인에 대한 정보는 **FAQ-862에서 제공됩니다**. … 초고속 인터넷 100Mbps 요금은 **FAQ-881에서** …"
- 본문 ID 노출 123 → 170. 새로 생긴 노출 79건 중 61건은 이런 **내용 인용**, 18건은 "FAQ-132와 FAQ-745는 관련이 없습니다"(SR-0001)처럼 **무관함을 설명**하는 문장이다.
- 원인(추정): 완결성 대상을 "질문의 답을 담은 FAQ"로 좁히고 "답을 담지 않은 FAQ는 옮기지 않는다"를 넣자, 모델이 **어떤 FAQ를 썼는지를 본문에서 밝히는** 방식으로 그 구분을 표현했다. 반면 evidence_ids 정의 문장(t1과 같음)에는 변화가 없어, 출처 표시가 필드에서 본문으로 옮겨 갔다. 라벨(PARTIAL)·근거 필드만 나빠진 것이면 정답률에는 영향이 작을 수 있다 — Judge로 확인해야 한다.

**SR은 회복이 부분적이다**
- 상태 일치 72 → 77(v4_t1 97). PARTIAL 28 → 23으로 아직 많다. 비슷한 문서의 절차를 설명한 뒤 "확인할 수 없다"로 끝나는 응답(SR-0003·0005·0016)이 남아 있다 — 정답 여부는 Judge가 필요하다.

**Judge에서 확인할 것**: SR·HR 정답이 96·87로 돌아왔는지 · 환각(PI 51 · SR 47 · HR 39)이 줄었는지 · NC·MC의 PARTIAL·근거 미기재 증가가 정답률에 영향이 있는지 · PI·NC·MC 누락 감소(누락만으로 오답 v4_t1b 45)가 유지되는지.
