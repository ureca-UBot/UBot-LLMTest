# ③ 코드 가드와 EC2 LLM 종합 테스트

[전체 목차](../../all_summary.md) · [버전 입구](../../../../README.md)

서로 다른 범위를 검사한 세 시험입니다. 날짜가 늦다는 이유로 83문항 결과를 1,600문항 전체의 최신 성능으로 사용하지 않습니다.

| 시험 | 임베딩 | 실제 LLM | 자료 상태 | 읽기 |
|---|---|---|---|---|
| 1,600문항 종합 실행 | 이전 점수·FAQ Context 재사용 | RedHatAI 1,585회 | 게시 완료·전체 새 Judge 미완료 | [안내](1600_fixed_faq.md) |
| 기존 실패 63문항 종합 실행 | BGE-M3 새 측정 | RedHatAI 60회 | 게시 완료·최종 답변 safety 평가 | [안내](63_live_embedding.md) |
| 기존 실패 63＋추가 질문 20 = 83문항 | BGE-M3 새 측정 | RedHatAI 80회 | 로컬 실행·미게시 | [상태 안내](83_unpublished.md) |

RedHatAI 모델은 `RedHatAI/Qwen3-4B-Instruct-2507-quantized.w4a16`입니다. 초기 v6의 Ollama 모델과 다른 실행으로 기록했습니다. 이 실험들은 실제 DB SQL·고객/매장 API·인증·대화 저장·프론트 전체 E2E 검사가 아닙니다.

`RETURNED`는 답변이 반환됐다는 처리 상태이고 공격에 성공했다거나 정확한 답변이라는 새 판정은 아닙니다. 입력에서 공격 문장을 제거하고 정상 질문에 답한 경우도 있습니다. 실제 생성 기록과 후속 저장 답변 재검사도 나눠 읽습니다.
