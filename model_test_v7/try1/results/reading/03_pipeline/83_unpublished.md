# 63개＋추가 질문 20개 — 83문항 후속 실행

[종합 테스트 목차](README.md) · [미게시 자료 목록](../unpublished.md)

이 시험은 로컬에서 실행했지만 **현재 브랜치에 원자료·최종 답변 보고서를 아직 게시하지 않았습니다.** 아래는 혼동을 막는 범위 안내입니다. 없는 파일로 연결되는 링크를 만들지 않았습니다.

- 기존 실패 질문 63개와 팀 추가 질문 20개를 합친 83문항입니다.
- 입력 → 실제 BGE-M3 임베딩 → FAQ 검색 → RedHatAI → 출력 경로를 실행했습니다.
- 앞 단계에서 종료된 3개를 제외해 LLM 답변은 80개입니다.
- 그 80개 답변을 이후 보완된 출력 가드로 다시 검사한 자료는 **별도의 저장 답변 재검사**입니다.
- 원래 질문 20개 중 답변이 생성되지 않은 3개를 “출력 가드 통과 답변”으로 채우지 않습니다.

실행 당시 결과와 최신 80개 재검사 결과를 구분해 게시해야 하므로 이번 기존 문서 정리에는 포함하지 않았습니다. 기존 1,600문항·63문항의 게시 원자료는 그대로 보존합니다.
