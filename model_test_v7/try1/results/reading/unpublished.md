# 아직 Git에 게시하지 않은 가드 테스트 자료

[전체 목차](../all_summary.md) · [AI 출력 검사](02_ai_output.md) · [종합 테스트](03_pipeline/README.md)

2026-10-15 정리 시점에 확인한 로컬 후속 자료입니다. 이 문서는 게시 여부를 안내하며 원자료를 새로 업로드한 것은 아닙니다.

| 자료 | 범위 | 이번 정리의 처리 |
|---|---|---|
| AI 출력 가드 4모델 기본 비교 | 기존 문제 답변 63개 × 4모델 | 미게시 상태 표시 |
| 83문항 실제 임베딩·RedHatAI 종합 실행 | 기존 63개＋추가 질문 20개 | 미게시 상태 표시 |
| 위 실행에서 생성한 80개 답변의 후속 출력 검사 | 실제 생성 답변 80개 | 생성 원본과 재검사를 구분해 표시 |
| 최신 코드 입력·출력 가드 재검사와 정상·경계 검수 | 이전 게시본 이후의 로컬 자료 | 기존 게시 결과와 구분 |

이 정리에서 로컬 절대경로 링크, 새 결과 JSON/JSONL, 코드·테스트 소스·실행기를 추가하지 않았습니다. 기존 원문·점수·판정은 바꾸지 않았습니다.
