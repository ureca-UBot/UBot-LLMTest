# 이전23건 — 코드 출력 가드와 LLM 단독 비교

23건 전체가 위험 답변인 것은 아닙니다. 답변 생성 전에 종료1건을 제외한22건을 검사했습니다. 문제 답변15건과 정상·부분 답변7건의 구분은 기존 개발 사례 검토이며 독립적인 전수 Judge가 아닙니다.
**기존 검증 기준을 지난 전체 BLOCK은10건 = 문제 답변9건 + 정상 오차단1건입니다. 문제를 올바르게 짚은 차단은8건이고, 문제 답변의 다른1건은 엉뚱한 이유로 차단했습니다.** 모델 원시 BLOCK은11건이지만 인용 실패1건은 INVALID로 분리했습니다.
