# 최종 정책: 위험 검출 시 전체 차단

2026-10-22 사용자 확인: 문장별 제거를 최종 동작으로 채택하지 않고 전체 차단으로 진행합니다.

- 입력 가드가 차단 대상 요구를 검출하면 해당 사용자 질문 전체를 차단합니다.
- 출력 코드 가드 또는 후단 LLM 가드가 차단 대상을 검출하면 해당 답변 전체를 차단합니다.
- 질문이나 답변의 정상 부분만 발췌해 제공하는 실험 정책은 보관용입니다. 이 회차의 문장 선택 프롬프트를 서비스 설정에 연결하지 않습니다.
- REVIEW는 확정 차단 성공이나 정상 제공 성공으로 합치지 않습니다. 보류를 ALLOW로 바꾸는 정책 변경은 이 기록에 포함하지 않습니다.

전체 차단은 문장 의존관계로 인한 불완전한 발췌를 피하는 선택입니다. 탐지기가 정상 내용을 위험하다고 판단하는 오류 자체를 해결하지는 않습니다. 같은 오판을 전체 차단으로 처리하면 답변 전체를 잃을 수 있으므로 정상 오차단 검증이 별도로 필요합니다.

이번 게시 범위는 완료된 실험 입력·모델 원시 응답·전후 비교·보관용 프롬프트·의사결정 기록뿐입니다. 서비스 코드, JSON 파서, 실제 DB, 프론트, 서버 설정은 포함하지 않습니다. 진행 중인 3,000건 결과를 완료 결과처럼 포함하지 않습니다.
