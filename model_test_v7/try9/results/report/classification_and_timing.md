# 분류 변화와 호출·시간

QuestionRouter는 Kiwi와 코드로 분리·멀티턴 표지를 확인합니다. 표지가 있으면 기존 AI 질문 정리를 호출하고 없으면 원문 먼저 검색합니다. 원문 검색 성공·캐시 적중 시 질문 정리 AI가 생략될 수 있습니다. 이번 시험은 검색 전까지만 실행했으므로 검색 실패 후의 뒤늦은 질문 정리 호출은 제외했습니다.

통합형도 검색 우선 경로에는 안전 판정이 필요합니다. 최초363건의 코드 통과191건 중 즉시 질문 정리72건, 원문 검색 우선119건입니다. 새300건에서는 코드 통과198건 중 즉시 질문 정리113건·검색 우선85건입니다.

새300건 논리 모델 호출은 통합형198회·별도형249회이며, 정확히 동일한 요청을 공유해 실제 새 호출은 총362회였습니다. 이전363건의 실제 새 호출은556회입니다.

두 구성이 함께 ALLOW한 정상 분류 대상46건의 평균 AI HTTP 처리 시간은 통합형2.441초·별도형2.558초, 중앙값2.500초·2.640초입니다. 평균 차이는 약0.12초입니다. 전체300건의 AI 시간 합계는 통합형231.175초·별도형222.405초로 통합형이 더 빠르지 않았습니다. 원문·방식 순서를 섞었으나 워밍업·접두부 캐시 영향은 남으며 실제 서비스 전체 지연이 아닙니다.

새 표본의 비교 가능한 검색어 변화는41건입니다. 차이 자체를 오류로 확정하지 않았습니다. 수동 검토에서는 통합형이 개인정보 신고와 대리 방문 업무를 합친 의심 사례, 별도형이 유해 연락을 유해 콘텐츠로 바꾼 사례가 있었습니다. 두 방식 모두 자해 요구를 안전하다고 판정한 뒤 정상 결합상품 검색어로 바꾸기도 했으나 이를 차단 성공으로 세지 않았습니다.
