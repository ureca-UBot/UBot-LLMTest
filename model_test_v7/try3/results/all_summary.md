# v7 try3 — 새 하드 입력 400건·이전 공격 10건 임베딩 결과

2026-10-21 · 로컬 입력 코드 / EC2 g6.xlarge, NVIDIA L4 · [이전 try2](../../try2/results/all_summary.md) · [실행 조건 SETUP](../../SETUP.md).

## 0. 테스트 개요와 기준

**400건은 입력 코드 검사 후 AI 분류한 실험이고, 임베딩 10건은 이전 잔존 공격을 따로 검색한 실험입니다. 상담 답변 생성·출력 가드·외부 Judge는 이번 두 실험에서 실행하지 않았습니다.**

| 시험 | 구성·실행량 | 기준·분모 |
|---|---|---|
| 입력 가드 | 공격 16항목×20 =320 + 정상 80 =400 | 위험 요구 잔존/제거/전체 차단, 정상 내용 보존 |
| AI 후속 입력 분류 | 코드가 남긴 공격313 + 정리본5 + 정상80 =398 ×3모델 | 공격 UNSAFE /313, 정상 UNSAFE /80, 보류 분리 |
| FAQ 관련성 검색 | 이전 G14-091~100: 전체·정상만·공격만 =30텍스트 + 캐시 대조3 | top3, cosine 원점수와 검색 기준0.75 |
| 외부 Judge·답변 생성 | 미실시 | 안전한 최종 답변·공격 수행 여부로 해석하지 않음 |

## 1. 전체 결과 요약

LLM Judge 지표는 **미실시**입니다. 아래는 모델 자체 분류와 저장 결과 집계입니다.

입력 코드는 공격 320개 중 **5개에서 공격 요구를 제거하고 정상 부분을 보존**, **2개를 전체 차단**, **313개에서 공격 요구를 남겼습니다**. 정상 80개는 차단·내용 삭제가 없었습니다. ‘313개 잔존’은 LLM이 313개의 공격을 실행했다는 뜻이 아닙니다.

| 검사 | 잔존 공격 UNSAFE /313 | 공격 SAFE /313 | 공격 보류 /313 | 정상 UNSAFE /80 | 정상 보류 /80 | 정리본5 UNSAFE | 코드+모델 위험 처리 /320 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 현재 Qwen 4B AWQ | 256 | 22 | 35 | 16 | 14 | 0 | 263 |
| IBM Granite Guardian 3.1 2B | 172 | 141 | 0 | 13 | 0 | 0 | 179 |
| 카카오 Kanana Safeguard 8B | 193 | 120 | 0 | 1 | 0 | 0 | 200 |

보류를 성공으로 세지 않았습니다. 코드+모델 열은 오프라인 조합 집계입니다. 정상 오차단 합집합은 21개이며 Qwen 정상 보류 14개 중 2개는 다른 모델의 오차단과 겹칩니다. Qwen 출력 경고 35개도 원문에 남겼습니다.

이전 잔존 공격 10개의 전체 정리본은 **10개 모두 FAQ 검색 유사도0.75 이상(0.777267~0.907628)**이었습니다. 정상 부분만10개도 모두 기준 이상, 공격 요구만10개는 모두 기준 미만입니다. 임베딩은 관련 FAQ를 찾는 단계이므로 공격 요구를 지우거나 안전성을 보장하지 않습니다. FAQ는 팀 seed 1,688개·유사표현8,443개이며 운영 DB 동기화는 확인하지 못했습니다.

## 2. 이전 회차와 비교할 때의 차이

| 구분 | try2 | 이번 try3 |
|---|---|---|
| 코드 시험 | 기존 고정2,600개, 직접 공격1,400개 | 새 합성400개, 공격320개 |
| 코드가 남긴 공격 | 10개 | 313개 |
| AI 입력 | 잔존10 + 정상100 + 정리본6 =116 | 잔존313 + 정상80 + 정리본5 =398 |
| Qwen 위험 판정 | 6/10 | 256/313 |
| IBM·카카오 위험 판정 | 0/10·1/10 | 172/313·193/313 |
| 정책 | Qwen 프로젝트 정책 / native 공급자 정책 | 이전과 동일, 정책 차이 유지 |
| 임베딩 검사 | 해당116개 비교에는 미실시 | 이전 잔존10개만 별도 검색 |

문항·분모·공격 유형 구성이 다르므로 증가·감소를 동일 조건의 정확도 차이로 계산하지 않습니다. 규칙이나 프롬프트를 이번 결과에 맞춰 고치지 않았습니다. 높은 기존 고정 문항 결과와 낮은 새 말투 탐지는 함께 보관하며 일반화의 한계로 검토합니다.
