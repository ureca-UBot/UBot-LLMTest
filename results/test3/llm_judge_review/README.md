# test3 저장 응답 LLM Judge 상세 평가

상태: **평가 완료(기존 생성 실패 별도)**

먼저 읽기: [핵심 해석과 모델별 검토 의견](interpretation.md). 아래에는 전수 집계와 문항별 판정 근거를 정리했다.

전체 3773개 평가 항목 중 3767개 채점, 6개 미채점, 0개 대기. 원본 답변 3건의 생성 실패/무응답이 내용·안전성 항목에 각각 반영된 수치다.

## 1. 평가 방법과 범위

- 이미 저장된 test3 답변을 수정한 세 스크립트로 평가했다. 답변 생성·임베딩·성능 테스트를 다시 실행하지 않았다.
- Judge는 gpt-6-astra / medium. 각 문항은 독립 요청이며 다른 모델 답변·속도·기존 자동 점수를 입력하지 않았다.
- 평가 기준은 test3-saved-v1이다. accuracy_hallucination_llm은 정확도·근거·표현, safety_llm은 지정 적대적 문항의 안전성 결과다.
- 내용 평가는 정확도·환각/근거·한국어 표현을 독립 판정한다. 안전성은 적대적 입력 유형의 지정 문항만 별도로 평가한다.
- 본측정 7개 모델 × 고유 300문항, 추론 OFF 4개 × 고유 300문항, 온도 대조군 7개 × 고유 40문항. 반복 2·3회차는 내용 정답률에 중복 반영하지 않았다.
- t0_think는 비교 그룹 이름이다. Qwen3만 실제 추론 ON이며 Gemma3·EXAONE은 저장된 think 값이 null이다.
- 정확도/환각률 분모는 성공적으로 채점된 답변이다. 생성 실패를 정답·환각 없음·SAFE로 처리하지 않으며 전체 예정 건수와 별도 미채점 수를 함께 표시한다.
- CORRECT는 AI의 기준 충족 판정이다. INSUFFICIENT_EVIDENCE는 평가용 근거 부족이며, 적절한 ABSTAIN과 다른 개념이다.
- 근거 4점의 경미한 문제는 minor_issues에 남기고 실질적 환각(1~3점)과 구분한다. 정확도와 환각은 동시에 발생할 수 있다.
- 그라운딩은 FAQ·대화·사용자 조건/정정·API 결과를 함께 참조한다. 정답 예시를 근거로 사용하지 않는다. 실제 검색기 Recall@K나 임베딩 성능을 측정한 결과는 아니다.
- 고정된 제공 Context에 대한 저장 응답 평가다. 실제 채팅→질문 임베딩→Vector DB top-k 검색→생성의 전체 서비스 정확도와 동일하지 않다.
- 원본 문서·응답·자동 채점·문항 245개 파일의 SHA-256을 재확인했다. 원본은 변경되지 않았다.
