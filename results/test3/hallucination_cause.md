# test3 환각 원인 분류 (규칙 위반 vs 판단 오류)

생성일: 2026-09-23 · 대상: 본측정 7개 모델(t0_think) + Qwen3 추론 OFF 4개 설정(t0_nothink) · 고유 300문항 · LLM Judge 전수 채점 결과

## 요약

### 본측정 7개 모델

Qwen3 모델은 추론 ON 결과다.

- 환각 답변 699건 중 문항 문제(C) 76건을 빼고 **623건을 분류**했다. 원인이 판정된 것은 428건, **판정 불가는 195건(31.3%)**이다.
- 판정된 428건: **A1 109 · A2 6 · P 57 · B1 98 · B2 36 · B3 54 · B4 68**. A 계열+P가 172건(40.2%), B 계열이 256건(59.8%)이다.
- **U(status 비판별)에 해당하는 모델은 없다.** 가장 낮은 Gemma3 4B도 판별력이 0.750이다. Gemma3 4B는 ANSWER만 내는 모델이 아니라, ABSTAIN이 필요한 자리에 CLARIFY를 쓰는 모델이었다.
- **판정 불가의 88%(171/195)가 보류 계열 교차다.** ABSTAIN↔CLARIFY 140건, ABSTAIN↔OUT_OF_SCOPE 31건이다. 트리 미해당으로 남은 22건은 모두 CONFLICT·OUT_OF_SCOPE가 얽힌 조합이다.
- 모델별 특징
  - **Qwen3 4B(40.0%) · Gemma3 12B(34.5%) · Qwen3 14B(30.2%)는 A1 비중이 가장 크다.** status 판단은 맞았는데 본문에서 지어낸 경우다.
  - **Qwen3 8B(20.0%) · Qwen3 14B(23.8%)는 P가 두드러진다.** 메뉴 경로나 절차처럼 Context 밖 내용을 자각 표현 없이 덧붙였다.
  - **Qwen3 1.7B는 B 계열이 71.8%(B1 42건)다.** 답이 없는데 있다고 판단하는 판단 자체의 오류가 대부분이다.
  - **EXAONE(B4 23건)과 Gemma3 4B(B4 27건)는 과소 판단이 많다.** EXAONE은 답이 다 있는데 PARTIAL로 낸 경우가 18건이고, Gemma3 4B는 부분 정보에서 PARTIAL 대신 CLARIFY를 낸 경우가 많다.
  - **Gemma3 4B는 판정 불가가 55.8%(교차 72건)다.** 이 모델의 A/B 비율은 대표성이 약하다.

### Qwen3 추론 OFF 4개 설정

- 환각 답변 406건 중 C 39건을 빼고 **367건을 분류**했다. 판정된 것은 281건(A1 75 · A2 2 · P 17 · B1 64 · B2 25 · B3 45 · B4 53)이고, **판정 불가는 86건(23.4%)**이다(교차 75, 트리 미해당 8, 출처 판별 불가 3).
- **추론을 끄면 모델별로 원인 구성이 이렇게 바뀐다(ON → OFF).**
  - **Qwen3 14B:** A1 19→29, B1 16→6, P 15→3. 보류 status는 더 잘 내지만 본문을 채우는 쪽(A1)으로 옮겨 갔다. 빈 컨텍스트에서 A1이 5→14건이다.
  - **Qwen3 8B:** P 14→2로 줄고 B4가 4→15로 늘었다. 부분 정보에서 PARTIAL 대신 CLARIFY를 낸 경우가 10건이다. 유사하지만 답 없음 15건 중 14건이 ABSTAIN↔CLARIFY 교차다.
  - **Qwen3 4B:** 환각이 41→87건으로 늘고 B4가 1→21건이다. 조건·예외·경계값(8건)과 적대적 입력(5건)에서 답할 수 있는 질문에 PARTIAL·CLARIFY를 냈다.
  - **Qwen3 1.7B:** 환각이 129→170건으로 늘었지만 B 계열 비중은 71.8% → 72.2%로 같다. ON이든 OFF든 판단 오류가 중심이다.
- **Qwen3 8B·14B는 추론을 켜면 P가 크게 늘었다(각각 2→14, 3→15).** 추론 과정에서 Context 밖 절차·경로를 덧붙이는 경향으로 보인다. 다만 모델당 건수가 작아 경향 수준으로만 본다.

### 환각 외 오답과 문항 검토 (7절)

- **환각이 없는 오답도 적지 않다.** 본측정에서 환각 없는 status 오류(S)가 255건, 환각 없는 내용 누락(M)이 144건이다. 환각 오답(562건)의 약 70% 규모다.
- **S는 교차 제외 후 166건이 남는다.** 추론을 끄면 과소 판단이 크게 늘어서, Qwen3 4B는 2→42건이다.
- **M은 대부분 문항·채점 기준 문제다.** 본측정 M 144건 중 96건(67%)이 문항 검토에서 수정 필요·경계로 판정된 문항에서 나왔다. M을 근거로 모델 교체를 판단하기는 어렵다.
- **C 문항 13개 중 8개는 문항 검토에서 적합 판정을 받았다.** 다시 분류하면 B1 18건, B3 10건이 가장 많다. 환각의 약 4분의 1은 수정 필요·경계 문항에서 나왔다(Qwen3 14B ON 32.4%).

| 코드 | 이름 | 원인 | 파인튜닝 기대 |
|---|---|---|---|

| B1 | 답변 가능 오판 | 답이 없는데 있다고 판단 | 중간 (대조 데이터 필요) |
| B2 | 범위 오판 | 일부만 있는데 전부 있다고 판단 | 중간 |
| B3 | 근거 혼동 | 다른 FAQ를 이 질문의 근거로 착각 | 중간 (유사 FAQ 대조 학습) |
| B4 | 과소 판단 | 답할 수 있는데 부분 답변·되묻기·보류로 판단하고, 그 본문에서 환각 | 중간 (과잉 보류 교정용 대조 데이터) |
| P | 사전지식 보충 | 자각 여부를 확인할 수 없음. A 성향으로 봄 | 중간~높음 |
| C | 문항 문제 | 데이터나 정답이 애매함 | 해당 없음 (데이터 수정) |
| U | status 비판별 | 모델 status가 판단을 반영하지 않음 | 판정 불가 |

### 적용 순서

대상은 Judge 근거 점수 1~3점(실질적 환각) 답변이다. 한 답변에는 라벨 하나만 붙는다.

1. **C** — 7개 모델 중 5개 이상이 같은 문항에서 환각을 내고 **같은 status**를 냈으면 그 문항의 환각 전체를 C로 뺀다. 사람 검토 전까지 집계에서 제외한다. **C는 본측정 7개 모델로만 판정**하고, 같은 C 문항 목록을 추론 OFF 설정에도 적용했다. OFF 설정까지 세면 같은 모델이 두 번 들어가기 때문이다.
2. **U** — 모델의 status 판별력이 0.6 미만이면 그 모델의 환각 전체를 판정 불가(U)로 둔다.
   - status 판별력 = (기대 ANSWER 문항에서 ANSWER를 낸 비율 + 기대 비ANSWER 문항에서 비ANSWER를 낸 비율) ÷ 2
3. **보류 계열 교차 제외** — 아래 두 쌍은 프롬프트에 구분 기준이 없어(명세 공백) 판정 불가로 뺀다. 양방향 모두 해당한다.
   - ABSTAIN ↔ CLARIFY
   - ABSTAIN ↔ OUT_OF_SCOPE (프롬프트에 ABSTAIN의 행동 규칙은 없고 "범위 밖 요청은 범위를 안내한다"만 있다)
4. 나머지를 기대 상태와 모델 status로 가른다.

| 기대 상태 | 모델 status | 라벨 |
|---|---|---|
| ANSWER 외 | 기대와 같음 | **A1** — 상태 판단은 맞았는데 본문에서 지어냄 |
| ABSTAIN / CLARIFY | ANSWER / PARTIAL | **B1** |
| PARTIAL | ANSWER | **B2** |
| ANSWER | PARTIAL / CLARIFY / ABSTAIN / OUT_OF_SCOPE | **B4** |
| PARTIAL | CLARIFY / ABSTAIN / OUT_OF_SCOPE | **B4** |
| ANSWER | ANSWER | 환각 문장의 출처로 가름 (아래) |
| 그 밖의 조합 (주로 CONFLICT 관련) | | 판정 불가 (결정 트리 미해당) |

B4의 서열은 ANSWER > PARTIAL > CLARIFY·ABSTAIN·OUT_OF_SCOPE이다. 기대보다 낮은 서열의 status를 냈으면 과소 판단으로 본다.

기대·모델 모두 ANSWER인 경우, Judge가 기록한 환각 사유(`hallucinated_claims[].reason`)로 출처를 가른다.

| 사유에 나타난 출처 | 라벨 |
|---|---|
| Context 안의 다른 FAQ·다른 요금제 조건을 옮겨 씀 | **B3** (다른 FAQ 혼동) |
| 정답 FAQ의 조건·수치·범위를 생략하거나 바꿈 | **B3** (정답 FAQ 왜곡) |
| Context 밖 내용 + 답변에 "일반적으로", "제공된 정보에는" 같은 자각 표현 있음 | **A2** |
| Context 밖 내용 + 자각 표현 없음 | **P** |
| 사유로 출처를 가를 수 없음 | 판정 불가 (출처 판별 불가) |

주장이 여러 개면 B3(다른 FAQ) → B3(왜곡) → A2/P 순으로 우선한다. 판단 오류가 하나라도 있으면 B로 보는 보수적 규칙이다.

### 한계

- **Thinking 로그가 저장돼 있지 않다.** `generation.jsonl`에는 최종 JSON만 있어서 "추론 과정에 자각이 드러나면 A1" 규칙은 적용하지 못했다.
- 기대·모델 모두 ANSWER인 경우의 출처 판정은 Judge 사유 문장에 키워드 규칙을 적용한 결과다. 규칙 적용 결과(test2·test3 합계 약 200건)를 AI가 읽고 명백한 오분류가 나온 규칙을 보정했다. **사람 검수는 아니며**, 경계 사례(예: 같은 FAQ의 범위 확대 vs Context 밖 추가)는 남아 있을 수 있다.
- A2/P를 가르는 자각 표현은 답변 전체에서 찾는다. 자각 표현이 환각 문장과 다른 곳에 있어도 A2가 된다.
- 모든 분류는 Judge 판정에 기대고 있다. Judge의 사람 채점 보정은 아직 하지 않았다.
- test3 본측정(temperature 0, Qwen3 추론 ON)과 Qwen3 추론 OFF 설정(temperature 0)을 대상으로 했다. temperature 0.8 대조군은 포함하지 않았다. Gemma3·EXAONE은 추론 모드가 없어 본측정 한 설정뿐이다.

남은 조합은 모두 **CONFLICT(충돌 고지)** 또는 OUT_OF_SCOPE가 얽혀 있다. CONFLICT는 "같은 대상에 서로 다른 내용의 FAQ가 있고, 시행일·버전·우선순위로 어느 쪽인지 정할 수 없을 때 충돌을 알리는" status다. 예를 들어 CF-0016은 일시정지 최대 기간이 90일(SYN-C05A)과 180일(SYN-C05B)로 엇갈리고 우선순위 정보가 없다.

- **ANSWER→CONFLICT (본측정 10건):** 6건은 적대적 입력 유형이다. 문서에 섞인 공격 지시를 정책 충돌로 받아들인 경우다. 나머지 4건은 시행일·대상으로 해소되는 충돌을 해소 불가로 판단했다. Gemma3 12B가 6건이다.
- **CONFLICT→ANSWER (본측정 6건, OFF 3건):** 해소할 수 없는 충돌을 알리지 않고 한쪽을 골랐다.
- **CONFLICT→PARTIAL·CLARIFY:** 충돌을 부분 답변이나 되묻기로 처리했다.

충돌 판단은 A/B 기준과 축이 달라서(문서 간 우선순위 판단) 라벨을 정의하지 않고 판정 불가로 두었다. 건수가 적어(본측정 22건, OFF 8건) 전체 해석에 주는 영향은 작다.

## 해석: 파인튜닝 관점

1. **판정 불가를 줄이는 게 먼저다.** 본측정 판정 불가 195건 중 171건이 보류 계열 교차(ABSTAIN↔CLARIFY·OUT_OF_SCOPE)다. status 정의(값별 사용 조건, ABSTAIN·CLARIFY·OUT_OF_SCOPE 구분 기준)를 넣은 프롬프트로 다시 측정하기 전에는 이 부분의 원인을 가를 수 없다.
2. **큰 모델(Qwen3 4B·14B, Gemma3 12B)은 A1+P 비중이 커서 파인튜닝 효율이 좋은 쪽이다.** 판단은 맞히고 출력에서 새는 경우가 많아서, "보류·부분 답변일 때 본문에 추측을 쓰지 않는다", "FAQ에 없는 메뉴·절차를 만들지 않는다"는 규칙을 지킨 예시만으로도 개선을 기대할 수 있다.
3. **Qwen3 1.7B는 B1 중심이라 소량 SFT로 고치기 어렵다.** 같은 질문에 답이 있는 Context와 없는 Context를 짝지은 대조 데이터가 필요하고, 그래도 용량 한계일 수 있다.
4. **B3의 정답 FAQ 왜곡은 대부분 조건 생략이다.** "지원되는 경우", "기준값 미포함", "요금제별 단가" 같은 조건을 빼거나 바꿨다. 조건을 보존한 답변 예시로 학습 데이터를 만들 수 있다.
5. **B4(과소 판단)는 B1과 반대 방향이라, 둘을 함께 학습해야 한다.** B1만 고치려고 "모르면 보류" 데이터를 넣으면 B4가 늘 수 있다. 답이 있는 Context와 없는 Context를 짝지은 대조 데이터에 "부분만 있는 경우 PARTIAL로 답할 만큼 답한다"는 예시를 함께 넣어야 한다. EXAONE, Gemma3 4B, Qwen3 4B·8B OFF가 여기에 해당한다.
6. **C 13개 문항은 사람이 먼저 검토해야 한다.** 특히 API 결과 답변과 멀티턴 대화에서 C 비중이 크다.
7. **추론 ON/OFF는 환각의 양뿐 아니라 원인도 바꾼다.** Qwen3 14B는 추론을 끄면 B1·P가 줄고 A1이 늘어서, 오히려 SFT로 고치기 쉬운 쪽으로 옮겨 간다. Qwen3 4B·8B는 추론을 끄면 B4(과소 판단)와 보류 계열 교차가 크게 늘어서, OFF 운영을 검토한다면 status 정의 보강이 먼저다. 운영 설정(ON/OFF)을 정한 뒤 그 설정의 원인 구성을 기준으로 학습 데이터를 설계해야 한다.
