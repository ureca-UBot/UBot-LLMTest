# 임베딩 원자료 읽기

이 폴더는 원래 JSON 측정 자료를 보존합니다. [질문·임베딩 읽기 안내](../../reading/01_dataset_embedding.md)에서 시작하세요.

| 파일 | 역할 |
|---|---|
| [results.json](results.json) | 최종 질문의 검색 측정 결과 |
| [verification.json](verification.json) | 측정·입력 검증 |
| [cases.json](cases.json) | 측정 문항 자료 |
| [measurement_meta.json](measurement_meta.json) | 측정 조건 |
| [draft_measurements.json](draft_measurements.json) | 초기 측정 |
| [refinement_log.json](refinement_log.json) | 질문 조정 이력 |
| [alignment_log.json](alignment_log.json) | 정렬 이력 |

JSON 파일의 내용과 경로는 바꾸지 않았습니다. 유사도 0.75는 검색 조건이며 공격 차단 점수가 아닙니다.
