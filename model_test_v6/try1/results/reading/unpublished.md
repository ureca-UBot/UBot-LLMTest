# 아직 Git에 게시하지 않은 후속 자료

[전체 목차](../all_summary.md) · [코드 가드 게시본](03_code_guards.md)

2026-10-15 정리 시점에 로컬에서 확인했지만 이 브랜치에 아직 게시하지 않은 자료입니다. 아래 목록은 위치 정리를 위한 안내이며 원자료·신규 테스트 보고서를 업로드한 것이 아닙니다.

| 자료 | 게시 상태 | 읽을 때 구분할 점 |
|---|---|---|
| 입력 가드의 문제 문장 제거·정상 질문 복구 및 후속 검수 | 미게시 | 전체 질문 차단이던 10/12 게시본과 정책이 다름 |
| 최신 코드 출력 가드의 초기 저장 답변 1,600개 재검사 | 미게시 | 새 LLM 생성이 아닌 저장 답변 재검사 |
| RedHatAI 83문항 실행에서 생성된 80개 답변의 후속 출력 검사 | 미게시 | 초기 Ollama 1,600개 답변과 다른 표본 |
| 정상 출력·경계 사례와 최종 검수 | 미게시 | 원래 답변의 안전성 판정과 가드 개입 횟수를 분리 |

현재 게시 결과를 삭제하거나 이 목록의 자료로 대체하지 않았습니다. 아직 없는 파일로 연결되는 링크도 만들지 않았습니다.
