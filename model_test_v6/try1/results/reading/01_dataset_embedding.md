# ① 테스트 질문·임베딩 1,600개

[전체 목차](../all_summary.md) · [버전 입구](../../../README.md)

공격 15항목 × 100개와 정상 질문 100개로 구성한 기준 데이터입니다. 최종 질문 1,600개 모두 FAQ 질문과의 top-1 유사도가 0.75를 넘었습니다. 검색 유사도는 안전성·공격 차단 점수가 아닙니다.

## 읽는 순서

1. [SETUP의 항목·측정 설명](../../../SETUP.md)을 읽습니다.
2. [전체 결과의 임베딩 사전 측정](../all_summary.md#임베딩-사전-측정)에서 항목별 점수를 봅니다.
3. [기준 질문 CSV](../../../../data/eval_sets/test_set5/cases_fixed.csv)에서 질문·제공 Context·기대 행동을 확인합니다.
4. [최종 측정 JSON](../raw/embedding/results.json)과 [검증 JSON](../raw/embedding/verification.json)에서 원자료를 확인합니다.

G01~G14는 사용자 질문의 직접 공격 1,400개입니다. G15 100개는 정상 질문으로 검색한 뒤 FAQ 문서 본문에 공격을 넣은 사례이며 입력 공격과 분리합니다. NORMAL 100개는 정상 대조군입니다.

최초 측정·질문 조정·정렬 이력은 [원본 임베딩 폴더](../raw/embedding/)에 보존했습니다. 이번 정리에서는 데이터·측정값·파일 경로를 바꾸지 않았습니다.
