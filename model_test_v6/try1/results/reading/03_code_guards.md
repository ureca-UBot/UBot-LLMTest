# ③ 코드 입력·출력 가드의 게시 결과

[전체 목차](../all_summary.md) · [버전 입구](../../../README.md)

여기는 이 브랜치에 **이미 게시한 결과**의 읽기 안내입니다. 이후 로컬에서 보완·검수한 결과와 현재 코드를 대표하는 최신 자료라고 혼동하지 않도록 날짜를 함께 봅니다. 코드·테스트 소스는 이번 문서 정리에 포함하지 않았습니다.

| 자료 | 이 브랜치의 마지막 게시본 | 읽을 곳 |
|---|---|---|
| 코드 입력 가드 | 2026-10-12 · 질문 1,600개 | [보고서](../input_guard/20261012-final/README.md) |
| 코드 출력 가드 | 2026-10-14 · 조건·근거 번호 보완 후 저장 답변 1,600개 | [보고서](../output_guard/20261014-condition-evidence/README.md) |
| 출력 보완 이전 기록 | 2026-10-14 · final 단계 | [이전 보고서](../output_guard/20261014-final/README.md) |

## 입력 가드 게시본

전체 질문 차단으로 집계했던 당시 정책에서 직접 공격 1,400개 중 814개 차단, 정상 100개와 추가 정상 62개 오차단 0이었습니다. 과거 UNSAFE 63개 중 입력에서 59개 차단, 검색 문서 공격 4개는 범위 밖이었습니다. 이후 “문제 문장만 제거하고 정상 부분 전달” 정책으로 바뀐 로컬 결과와 같은 집계로 합치지 않습니다.

## 출력 가드 게시본

초기 Ollama의 저장 답변 1,600개를 재검사한 결과입니다. 10/14 조건·근거 보완 게시본은 원문 유지 1,300 / 일부 제거 280 / 안내 종료 20입니다. 새 LLM·Judge·임베딩·DB 실행이 아닙니다. 가드가 개입했다는 수치가 새로운 SAFE 판정을 뜻하지 않습니다.

## 아직 게시하지 않은 후속 자료

[미게시 자료 목록](unpublished.md)에 입력 문장 복구, 최신 1,600개 재검사와 80개 답변 재검사, 정상·경계 검수를 따로 표시했습니다. 이 정리에서 해당 원자료나 로컬 파일 링크를 업로드하지 않았습니다.

다른 실험의 연결된 기록은 우리 [AI 가드·RedHatAI 종합 테스트 브랜치](https://github.com/ureca-UBot/UBot-LLMTest/tree/test/ai-guard-input/model_test_v7)에서 볼 수 있습니다. 두 브랜치를 병합한 것은 아닙니다.
