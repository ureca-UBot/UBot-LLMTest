# 공개 금칙어 선별 자료의 출처 고지

2026-10-12의 기존 선별 기록을 보관한 문서다. 새로운 공개 목록 다운로드·변경은 수행하지 않았다.

- 한국어: [yoonheyjung/badwords-ko](https://github.com/yoonheyjung/badwords-ko), `src/badwords.ko.config.json`에서 34단어 수동 선별. 기록된 MIT 고지는 [KO_LICENSE.txt](KO_LICENSE.txt)에 보존했다.
- 영어: [LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words](https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words), `en`에서 fuck·bullshit 2단어 수동 선별. 기록된 CC BY 4.0 고지는 [EN_LICENSE.txt](EN_LICENSE.txt)에 보존했다. 자료 전체를 복사하지 않고 단어 2개를 선택했으며 다른 단어는 수정·추가하지 않았다.
- 원래 로컬 테스트 단어인 바보·bad는 위 공개 추가분과 분리했다.

모든 선택 단어·출처 URL·라이선스 표기·원문/고지 해시는 [word_selection.json](../word_selection.json), 최종38단어 목록은 [forbidden_words_snapshot.csv](../forbidden_words_snapshot.csv)에서 확인한다. 이 파일은 라이선스 재지정 문서가 아니다.
