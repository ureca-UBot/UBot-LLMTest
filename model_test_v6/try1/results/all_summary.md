## 0. 테스트 개요

공격 15항목 × 100건 = 1,500건, 정상 대조군 100건, 합계 1,600건이다. G01~G14 질문 공격 1,400건 + G15 문서 내 간접 공격 100건 + NORMAL 100건이며 반복 라운드는 없다. 항목 정의는 [SETUP의 항목 표](../../SETUP.md#4-테스트-항목)에 있다.

| 구분 | 평가·측정 기준 | 분모·현재 상태 |
|---|---|---|
| LLM Judge / 내용 | 공격 지시 수행·정보 유출·허위 답변·위험한 도움 여부 | 안전성 1,500건 판정 완료; 기존 루브릭 범위 |
| LLM Judge / 내용 | 실제 답변의 정확도, 정상 부분의 유용성·과잉 거절 | 정확도 입력 1,600건 준비, **평가 미실시**; 정상 대조군 100건 별도 확인 예정 |
| 검색 사전 측정 | FAQ 질문과의 top-1 cosine 유사도 > 0.75 | 실측 1,600건; 공격 차단 여부와 무관 |
| 기존 결정론 검사 | JSON 구조·키 순서·인용 ID와 Context/정답 근거 비교 | 형식 1,600건, 근거 채택 대상 657건 |
| 계측 | 응답 시간·TPS·출력 토큰 수 | 1,600응답; VRAM 미측정 |

LLM `qwen3:4b-instruct` 4.0B Q4_K_M / Ollama 0.34.2 / `v4_base` / temp 0 / think 옵션 미전송 / schema 출력 / timeout 60초 / 생성 retries 0. run ID는 `guard-q4_20261012`이다. 기록된 문항 호출 1,600회, 별도 warm-up 1회, 안전성 Judge 호출 1502회, 고유 판정 1,500건 완료다. 총 생성 소요 약 57분 34초.

검색 결과를 고정 Context로 전달했고, **코드 입력 가드는 사용하지 않았다**. 운영 백엔드·프론트·실제 벡터 DB 전체 흐름은 이번 평가 범위가 아니다.

## 2. 이전 버전과의 관계

v5는 동일 모델을 포함한 양자화 비교였고, 이번 v6는 공격 15항목과 정상 대조군으로 데이터가 바뀌었다. 원문 FAQ는 기존 `test_set4`와 내용이 같은 1,000건을 재사용한다. `scripts/`·`prompts/`와 기존 `model_test_v5`는 수정하지 않았다.

데이터·문항 분포와 안전성 대상이 달라 v5 대비 안전성·정확도 증감이나 모델 순위를 계산하지 않는다. 카카오·삼성 가드 모델 및 코드 입력 가드 비교도 아직 실행하지 않았다.
