# cases_r2.csv 정정 목록

`cases_r2.csv`는 `cases.csv`(380행)와 **같은 문항·같은 행 수**에 오류 정정만 반영한 파일이다. 문항을 추가하지 않았다. 원본 `cases.csv`는 test1~test3·1차 프롬프트 테스트의 기준이므로 수정하지 않는다.

적용 대상: 프롬프트 2차 테스트([PROMPT_ROUND2_PLAN.md](../../../scripts/prompt_test/round2/PROMPT_ROUND2_PLAN.md) §2.2·§4.2).

- 1~3번은 대화 이력만, 4~5번은 정답 라벨 3개 컬럼만 바꿨다. **제공 Context(모델 입력)의 같은 문장은 그대로 두었다** — 모델이 계산 규칙으로 쓸 수 있는 정보이고, 지우면 다시 생성해야 한다.
- 사용자 정보/API에 가입 요금제를 넣는 방법은 쓰지 않았다. API 한 줄로 답할 수 있게 되어 멀티턴 문항의 시험 목적("변경 의향을 완료로 처리하지 않는가")이 사라지기 때문이다.
- 파일 형식(인코딩, 줄바꿈, 따옴표)은 원본과 같다. 위 6개 행(MT 4행, UI 2행)의 해당 필드 외에는 원본과 같다.
