# cases_r2.csv 정정 목록

`cases_r2.csv`는 `cases.csv`(380행)와 **같은 문항·같은 행 수**에 오류 정정만 반영한 파일이다. 문항을 추가하지 않았다. 원본 `cases.csv`는 test1~test3·1차 프롬프트 테스트의 기준이므로 수정하지 않는다.

적용 대상: 프롬프트 2차 테스트([PROMPT_ROUND2_PLAN.md](../../../scripts/test3/PROMPT_ROUND2_PLAN.md) §2.2·§4.2).

## 정정 내역

| 1 | 2026-09-27 | MT-0109, MT-0109-R2, MT-0109-R3 | 대화 이력 (첫 발화) | 사용자: 다온 요금제가 궁금해요. | 사용자: 지금 다온 요금제 쓰고 있어요. | 정답(ANSWER, 현재 다온 월 31,000원)은 현재 가입 요금제가 다온임을 전제하는데, "궁금해요"만으로는 가입을 추론할 수 없다 | 모델 입력 변경 → v2 재생성·재채점 |

- 질문, 제공 Context, 사용자 정보/API, 기대 행동, 필수 포함 사실, 정답 예시, 기대 응답 상태는 **바꾸지 않았다**.
- 사용자 정보/API에 가입 요금제를 넣는 방법은 쓰지 않았다. API 한 줄로 답할 수 있게 되어 멀티턴 문항의 시험 목적("변경 의향을 완료로 처리하지 않는가")이 사라지기 때문이다.
- 파일 형식(인코딩, 줄바꿈, 따옴표)은 원본과 같다. 위 4개 행의 `대화 이력` 필드 외에는 바이트 단위로 동일하다.
